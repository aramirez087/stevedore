```swift
public enum Confidence: Int, Comparable, Sendable, CaseIterable {
    case low = 0, medium = 1, high = 2

    public static func < (lhs: Self, rhs: Self) -> Bool { lhs.rawValue < rhs.rawValue }

    // Score thresholds (inclusive lower bound)
    static func from(score: Double) -> Self {
        if score >= 0.7 { return .high }
        if score >= 0.4 { return .medium }
        return .low
    }
}
```

### AppMetadataReader

`public struct AppMetadataReader: AppMetadataReading` — synchronous, no actor.

Algorithm:
1. Check `bundleURL.appending(path: "Contents/Info.plist")` exists → else throw `.notAnAppBundle`.
2. Load `Data`, parse with `PropertyListSerialization`.
3. Extract `CFBundleIdentifier` (required), `CFBundleExecutable` (required) → else throw `.invalidInfoPlist`.
4. `CFBundleName` / `CFBundleDisplayName` optional; fallback to `bundleURL.deletingPathExtension().lastPathComponent`.
5. `CFBundleShortVersionString` optional; store as `version: String?`.
6. Compute bundle size via `FileManager.enumerator` summing `URLResourceKey.fileSizeKey` for non-directory entries.

### MatchScorer

`public enum MatchScorer` — pure functions, no state.

```swift
// Returns score in 0.0…1.0 and human-readable reason.
public static func score(url: URL, metadata: AppMetadata) -> (score: Double, reason: String)

// Convenience: returns Confidence + reason.
public static func confidence(url: URL, metadata: AppMetadata) -> (Confidence, String)
```

**Scoring rules (checked in order, first match wins):**

| Condition | Score | Reason |
|---|---|---|
| Last reverse-DNS component of `bundleID` (≥4 chars) found in URL path (lowercased) | 0.9 | "Bundle ID match" |
| `bundleName` (≥3 chars, lowercased) found in URL path (lowercased) | 0.7 | "App name match" |
| `executableName` (≥3 chars, lowercased) found in URL path (lowercased) | 0.5 | "Executable name match" |
| None of the above | 0.1 | "Partial match" — **excluded from scan results** |

The scanner discards any candidate returning score 0.1 (the catch-all). Only scores ≥ 0.4 produce
`Confidence.medium` or higher; scores 0.1–0.39 produce `Confidence.low` and are still included
(the UI collapses them under "Show all").

> **Minimum-length guard prevents false positives:** A bundleID component like "app" or "pro"
> (< 4 chars) does NOT trigger the high-confidence path.

### UninstallExecutor

`public actor UninstallExecutor: UninstallExecuting`

```swift
public func execute(plan: UninstallPlan) async throws {
    // 1. Trash non-admin selected files first
    for file in plan.selectedFiles where !file.requiresAdmin {
        try FileManager.default.trashItem(at: file.url, resultingItemURL: nil)
        // Wrap FileManager errors in UninstallerError.trashFailed
    }
    // 2. Trash the app bundle last
    try FileManager.default.trashItem(at: plan.appMetadata.bundleURL, resultingItemURL: nil)
}
```

**Uses `trashItem` exclusively.** Never `removeItem`. Tests verify this with a source-grep assertion.

**Default selection (applied immediately after scan completes):**
```swift
func applyDefaultSelections(files: [AssociatedFile]) {
    selectedIDs = Set(files.filter { $0.confidence == .high && !$0.requiresAdmin }.map(\.id))
}
```

**`load` validation (before entering scan state):**
1. `appURL.pathExtension == "app"` — otherwise set `dropError` and return, keeping `scanState == .idle`.
2. `FileManager.default.fileExists(atPath: appURL.appending(path: "Contents/Info.plist").path(...))` — same.
3. If both pass → `scanState = .scanning`, kick off Task.

**Async task pattern (avoid retain cycle — see cerebrum Do-Not-Repeat 2026-05-02):**
```swift
scanTask = Task { [weak self] in
    // capture Sendable values before the loop
    let metadataReader = self?.metadataReader
    let scanner = self?.scanner
    do {
        guard let self else { return }
        let metadata = try metadataReader!.readMetadata(from: appURL)
        self.appMetadata = metadata
        let files = try await scanner!.scan(for: metadata)
        guard let self else { return }
        self.scanState = .ready(files)
        self.applyDefaultSelections(files: files)
    } catch {
        guard let self else { return }
        self.scanState = .failed(error.localizedDescription)
    }
}
```

> **Note on retain-cycle pattern:** The cerebrum Do-Not-Repeat (2026-05-02) warns that
> `guard let self else { return }` BEFORE a `for await` loop creates a retain cycle.
> For a non-loop Task body, the standard `[weak self]` + `guard let self else { return }` is
> correct. The warning only applies to `for await` loop bodies.

## Design Decisions

| Decision | Rationale |
|---|---|
| Engine built in Phase 1 of Session 25 | Session 15 was never executed |
| `AppMetadataReader` is `struct` | Pure synchronous function; no mutable state; `struct` is the default |
| `AssociatedFilesScanner` is `actor` | Async directory enumeration; actor isolates any intermediate state |
| `UninstallExecutor` is `actor` | FileManager mutations need actor serialization for safety |
| Protocols live in `Protocols/` subdirectory | Consistent with session 01 pattern; one type per file |
| Fakes in `Sources/…/Testing/` (production target) | Importable by UITests without `@testable`; same pattern as Core/Testing fakes |
| `@ObservationIgnored` on injected deps | Prevents `@Observable` from wrapping non-`Sendable` existentials in observation accessors → Swift 6 warning |
| `ScanState` and `AssociatedFileSortKey` at file scope | SwiftLint `nesting` rule rejects types nested inside a class |
| `displayedFiles` is computed (not stored) | Eliminates stale-slice bugs; `@Observable` auto-invalidates any dependent view |
| Low-confidence collapsed, not omitted | User may still want to see everything; "Show all" toggle reveals without a new scan |
| `requiresAdmin` disables Toggle; not just unchecked | Users must not be able to select system paths even with keyboard; enforced at ViewModel level too |
| `onConfirm` calls `onDismiss()` immediately | MVP: fire-and-forget trash; error handling is out of scope |
| `dropDestination(for: URL.self)` | `URL: Transferable` on macOS 14+; no custom `Transferable` needed |
| `trashItem` exclusively in `UninstallExecutor` | Safety guarantee; test verifies no `removeItem` in source |

## Risks and Mitigations

| Risk | Mitigation |
|---|---|
| **Quality gate: `swiftlint --strict --path <dir>` is invalid** | Use `swiftlint --strict <dir>` (positional args). See cerebrum Do-Not-Repeat 2026-05-02. |
| **Quality gate: `swiftformat --lint <paths>` order** | Use `swiftformat <paths> --lint` (paths first). See cerebrum Key Learnings. |
| **Test filter: `--filter UninstallerUITests` matches nothing** | Use `--filter "UninstallerViewModel\|UninstallerSheet"` (class-name substrings). See cerebrum Do-Not-Repeat 2026-05-02. |
| `KeyPathComparator<AssociatedFile>` compile error on `\.url.lastPathComponent` | `URL.lastPathComponent` is `String`; `String: Comparable`. This is fine. |
| `NSLock.lock()` is `@available(*, noasync)` in `FakeUninstallExecutor` | Use `OSAllocatedUnfairLock`. See cerebrum Decision Log 2026-05-02. |
| `URL(fileURLWithPath:)` returns non-optional but deprecated | Use `URL(filePath:)` (macOS 13+, non-optional, non-deprecated). |
| `SwiftLint` cyclomatic complexity in `MatchScorer.score` | Use early returns with guard; score is already structured as first-match-wins. If still over 12, extract helper function. |
| `ContentUnavailableView` macOS 14+ | Confirmed safe — our deployment target is macOS 14. |
| `Table` sort with `\.confidence` (Confidence: Comparable) | `Confidence` has a manual `<` implementation via rawValue. Confirm `KeyPathComparator` uses `<` — it does. |
| Large bundles: `computeBundleSize` blocks on main actor | Call `AppMetadataReader.readMetadata` from `Task` (already inside async task in ViewModel). `computeBundleSize` runs in the Task context, not main actor. No `.detached` needed since the whole `load(appURL:)` is already inside a `Task`. |
| `@testable import UIUninstallerUI` — is `@testable` needed? | `UninstallerViewModel`, `ScanState`, `AssociatedFileSortKey` are all `public`. Plain `import UIUninstallerUI` is sufficient. |
