## Actual Design Decisions

### 1. `PreviewService` is a plain `actor`, not `@MainActor`

All preview/thumbnail generation runs on a cooperative thread pool actor. This is the
structural guarantee for the "never blocks the main actor" exit criterion — the type
system enforces it without any runtime assertions.

### 2. Renderers are non-throwing `public enum` namespaces

All file I/O in renderers uses `try?` internally; functions return `PreviewPayload?`
(nil on any failure) rather than throwing. This simplifies call sites in `PreviewService`
which uses `await` (not `try await`) when calling renderers. QL fallback uses `try?` to
normalize `QLThumbnailGenerator` domain errors (unsupported type) to `nil`.

### 3. All data crossing actor boundaries is `Data`

`NSImage` is not `Sendable`. `NSAttributedString` is not `Sendable`. All renderers
convert to `Data` (PNG or RTF) before returning, so every `PreviewPayload` carries
only `Sendable` types. No `@unchecked Sendable` needed anywhere.

### 4. `ThumbnailGenerator` uses callback API + `withCheckedThrowingContinuation`

The async `generateBestRepresentation(for:)` API was found to require special handling
for the result type. The implementation uses `QLThumbnailGenerator.shared.generateBestRepresentation(for:completionHandler:)` bridged via `withCheckedThrowingContinuation`.
Inside the callback, `CGImage` (not `NSImage`) is used — `CGImage` is `Sendable` and
available from `QLThumbnailRepresentation.cgImage`; this avoids any `@MainActor` issue
with `NSImage` access inside a concurrent callback. The PNG is produced via
`NSBitmapImageRep(cgImage:)`.

### 5. `Language` at file scope with dictionary-based lookups

The `Language` enum and its keyword/extension lookup tables live at file scope (not
nested inside `CodePreviewRenderer`), satisfying SwiftLint's `nesting` rule.
Extension→language and language→keywords are stored as file-scope `let` dictionaries
rather than `switch` statements, keeping cyclomatic complexity ≤ 2 per function.
`Language.detect(extension:)` delegates to `codeLanguageExtensions[ext] ?? .unknown`.

### 6. `PreviewCache` uses `NSCache.totalCostLimit` for byte enforcement

`NSCache.totalCostLimit = byteLimit` is set at initialization; `data.count` is passed
as cost on every `setObject`. LRU eviction is handled natively by `NSCache`. The
`CachedPreview: NSObject` wrapper is required because `NSCache` expects `NSObject` values.

### 7. `ThumbnailGenerator` inflight coalescing via actor-isolated `[String: Task]` dict

The first caller for a given `(url, size)` key creates a `Task` and stores it in the
actor-isolated `inflight` dict. Subsequent concurrent callers find the task and `await`
its `.value`. After completion (success or error), the key is removed so future calls
start fresh. `withTaskCancellationHandler` propagates consumer cancellation to the inflight task.

### 8. `QuickLookPanelController` protocol stubs use `MainActor.assumeIsolated`

`QLPreviewPanelDataSource` / `QLPreviewPanelDelegate` are `@objc` protocols whose methods
AppKit always calls on the main thread. The `nonisolated` required stubs use
`MainActor.assumeIsolated { … }` to safely access the `@MainActor`-isolated `previewItems`
array without triggering Swift 6 isolation errors.

### 9. Renderer dispatch order in `PreviewService`

1. Image extensions (`png`, `jpg`, `jpeg`, `gif`, etc.) → `ImagePreviewRenderer`
2. Code extensions (`swift`, `py`, `js`, `ts`, `java`, etc.) → `CodePreviewRenderer`
3. Text extensions (`txt`, `md`, `markdown`, `csv`, `log`, etc.) → `TextPreviewRenderer`
4. Magic-byte sniff: no null bytes in first 4 KB → `TextPreviewRenderer`
5. Fallback → `ThumbnailGenerator` (QuickLook thumbnail at 512×512)

### 10. Package.swift not modified

All required frameworks (`QuickLookThumbnailing`, `QuickLookUI`, `AppKit`) are macOS
system frameworks. `FeaturesPreview` retains `extraDependencies: []`.

## Risks and Mitigations

| Risk | Mitigation |
|---|---|
| `QLPreviewPanel.shared()` returns `nil` in headless CI | All `QLPreviewPanel` access guarded; `QuickLookPanelController` tests will skip without a display; documented in handoff |
| `NSCache` eviction is advisory, not immediate | Tests use small `byteLimit` relative to payloads; assert "no crash" + "some eviction" rather than strict cap; handoff documents this |
| `NSBitmapImageRep` may become `@MainActor` in future SDK | If this happens, replace with `CGImageDestination` (ImageIO) for PNG conversion — no `@MainActor` dependency |
| `NSRegularExpression` rebuilt per render call (code renderer) | Acceptable for preview panel usage; cache if benchmarking reveals latency |
| Null-byte text sniff can misclassify null-free binary headers | Fallback to QL thumbnail handles these gracefully; documented as known limitation |
| `swiftformat --lint` flag order (0.59 bug) | Always pass paths before `--lint`: `swiftformat Sources/... Tests/... --lint` (per cerebrum) |
| SwiftLint `nesting` rule for `Language` enum | `Language` is at file scope, not nested inside `CodePreviewRenderer` enum |
| SwiftLint `cyclomatic_complexity` for keyword dispatch | File-scope dictionaries (not switches) keep all function bodies at complexity ≤ 2 |
| `@testable import` needed for internal types in tests | `Language`, `resample`, `detectAndDecode` are `internal`; tests use `@testable import FeaturesPreview` |
