## 2. Design decisions and rationale

### 2.1 `PathUtilities.swift` — extension on `FilePath`, not a new type

`FilePath` already has `parent`, `appending([String])`, `lastComponent`,
`posixString` defined in `Sources/Core/Types/FilePath.swift`. A `public extension
FilePath` in a separate file under `Utilities/` adds behavior without modifying
the type definition — satisfying the constraint "No public surface added to
`Sources/Core/Types` or `Sources/Core/Protocols`".

**Key invariants:**
- `relative(to:)` returns `[]` (empty array) when `self == base`. It returns
  `nil` when `base` is not a prefix or when schemes differ. The empty-vs-nil
  distinction is load-bearing: `nil` means "no relationship"; `[]` means "same
  path, zero hops".
- `commonAncestor(_:_:)` walks the component arrays in lockstep via `zip` and
  collects the common prefix. Returns `nil` only on scheme mismatch.
- `appending(posix:)` reuses `FilePath.init(scheme:posix:)` which eagerly
  normalizes `..` and `.` — so relative fragments compose safely.
- `displayName` returns `lastComponent` for non-root paths, and
  `scheme.rawValue + ":/"` for root paths (e.g., `"sftp:/"`) so UI list rows
  are never empty and remote root items are unambiguous in the sidebar.
- `localizedDisplayNameCompare` uses `[.caseInsensitive, .numeric,
  .diacriticInsensitive]` options so `"file10"` sorts after `"file2"`.
- `from(urlString:)` maps `file://` → `.local`, `sftp://` → `.sftp`,
  `ftp://` → `.ftp`, `http/https` → `.webdav`, `s3://` → `.s3`,
  `smb://` → `.smb`; returns `nil` for unknown schemes and invalid URLs.

### 2.2 `ByteCountFormatter+Stevedore.swift` — `ByteSizeFormatter` struct

`Foundation.ByteCountFormatter` is an `NSObject` — not `Sendable`. The
solution is a `Sendable` value-type wrapper (`struct`) that stores only
primitive configuration and constructs a fresh `ByteCountFormatter` inside each
`string(fromBytes:)` call. No shared mutable reference is ever passed across
actor boundaries.

**Critical caveat (macOS SDK):** `ByteCountFormatter` has no `locale` property
accessible via the public API on macOS. The `locale: Locale` field stored in
`ByteSizeFormatter` cannot currently be applied to the underlying formatter.
Tests must compare against a reference `ByteCountFormatter` built with the same
`countStyle`, rather than asserting locale-specific string literals.

**API:**
- `init(mode: Mode = .binary, locale: Locale = .current, allowsZeroRepresentation: Bool = true)`
- `func string(fromBytes bytes: Int64) -> String` — negative values are
  formatted from their absolute value with a leading `"-"` prepended.
- `func string(from attributes: FileAttributes) -> String?` — returns `nil`
  when `sizeInBytes` is `nil`.

### 2.3 `DateFormatter+Stevedore.swift` — `StevedoreDateFormatter` struct

Same `Sendable` wrapper pattern: value-type config (`locale`, `calendar`,
`timeZone`), Foundation formatter instantiated per call.

- `relative(_:relativeTo:)` — uses `RelativeDateTimeFormatter` with
  `unitsStyle = .full`, `dateTimeStyle = .named`.
- `mediumAbsolute(_:)` — uses `DateFormatter` with `dateStyle = .medium`,
  `timeStyle = .short`.
- `smartListing(_:relativeTo:)` — "Today at HH:MM" / "Yesterday at HH:MM" /
  falls back to `mediumAbsolute`. Uses `Calendar.isDateInToday`,
  `Calendar.isDateInYesterday`, and `Calendar.isDate(_:inSameDayAs:)`.

**macOS SDK note:** `TimeZone(secondsFromGMT:0)` returns `TimeZone?` on the
macOS 26 SDK, which requires force-unwrapping. Tests must use `TimeZone.gmt`
(macOS 13+, non-optional) to stay warning-clean under `-warnings-as-errors`.

### 2.4 `SortDescriptors.swift` — `FileItemSortDescriptor` struct

Designed as a `Sendable, Hashable` struct with `callAsFunction(_:_:)` so it can
be passed directly to `Array.sorted(by:)` and stored in view-model state.

**Comparator semantics (order of application):**
1. **`directoriesFirst`** — checked first, never inverted by `ascending`. A
   descending-name sort still puts directories on top.
2. **Primary key comparison** per `key` (`.name`, `.size`, `.modified`, `.kind`,
   `.fileExtension`).
3. **`ascending` flag** — flips the primary result. The `directoriesFirst`
   result from step 1 is never flipped.
4. **Stable tiebreaker** — when primary keys are equal, locale-aware name
   comparison is applied, ensuring deterministic output regardless of input
   permutation.

**`fileExtension` key:** extracts via `String.lastIndex(of: ".")` applied to
`displayName`. "archive.tar.gz" → "gz". Names without "." return `""` so they
sort before any extension in ascending order.

**`ComparisonResult.flipped`:** private extension that swaps ascending ↔
descending; not exposed in the public API.

**Convenience statics:** `.byName`, `.bySize`, `.byModified`, `.byKind`,
`.byExtension` — pre-built with sensible defaults.

### 2.5 `Filters.swift` — `FileItemFilter` + `GlobMatcher`

`FileItemFilter` stores a `@Sendable (FileItem) -> Bool` predicate typealias.
All built-in filters and combinators return new `FileItemFilter` instances
without mutation — compatible with Swift 6 strict concurrency.

`GlobMatcher` is a `public enum` (namespace pattern) with no cases, a single
public entry point `matches(pattern:path:caseSensitive:)`.

**Glob semantics:**
- `?` — exactly one character within a single path segment; never crosses `/`.
- `*` — zero or more characters within a single segment; never crosses `/`.
- `**` — zero or more complete path components (including zero). Consecutive
  `**` segments are collapsed.
- Patterns **without** `/` are internally prefixed with `**/` so `*.swift`
  matches any `.swift` file at any tree depth.
- Patterns **with** `/` are matched as-is from the root of `posixString`.
- Bracket sets and brace expansion are NOT supported (documented; deferred to
  the rename engine session).

**Implementation:** two-stage matching. Outer loop (`matchComponents`)
iterates component pairs with a `**` backtrack point. Inner loop
(`matchSegmentChars`) uses a classic backtracking star-match algorithm on
`[Character]` arrays.

**SwiftLint compliance:** `**` range iteration uses `(range).contains { }` over
`for i in range where { }` to satisfy the `for_where` rule while keeping
cyclomatic complexity below 12.

### 2.6 `AsyncSequence+Helpers.swift` — three operators

**macOS 14 constraint:** `AsyncSequence<Element, Failure>` existential with a
bound `Failure` is macOS 15+ only. All helpers return the concrete
`AsyncThrowingStream<Output, any Error>`, consistent with how
`FileSystemProvider.enumerate` is defined in Session 01.

Extension constraint: `where Element: Sendable, Self: Sendable` — required to
safely capture elements into `Task` closures.

**`chunked(by:)`** — accumulates into a local buffer; yields when full or
upstream finishes. `continuation.onTermination` cancels the worker task.
Precondition: `size >= 1`.

**`throttled(for:)`** — two tasks: an upstream task that continuously writes to
an actor-isolated `ThrottleState<Element>` cell, and a timer task that polls
every `interval` and forwards the latest value via `takeLatest()`. The final
element is forwarded on upstream completion. Both tasks cancelled via
`continuation.onTermination`.

**`withProgress(bytesTotal:phase:report:)`** — forwards every element
unchanged; calls the `@Sendable` async `report` closure with a `Progress`
snapshot after each element. Byte accumulation: if `Element == FileItem` and
`attributes.sizeInBytes != nil`, accumulates actual bytes. Otherwise, `bytesDone`
carries the item count. **Non-obvious invariant:** `bytesDone` may hold item
counts, not bytes, when sizes are unavailable.

**`ThrottleState` actor:** private actor with `setLatest(_:)` /
`takeLatest() -> Element?` for safe cross-task coordination.

### 2.7 `Result+Helpers.swift` — helpers and `StevedoreErrorBridge`

Three extensions on `Result<Success, Failure>` (and one on
`Result<Success, any Error>`), plus `StevedoreErrorBridge`.

**Touch-glob constraint:** Adding a static func to `StevedoreError` would
require modifying `Sources/Core/Errors/StevedoreError.swift`, outside the
declared `Sources/Core/Utilities/` touch-glob. `StevedoreErrorBridge` is
therefore a `public enum` (namespace) in `Result+Helpers.swift`.

**`StevedoreErrorBridge.map(_:)` mapping rules (applied in order):**
1. Already a `StevedoreError` → passthrough (avoids double-wrapping).
2. `CancellationError` → `.cancelled`.
3. Anything else → `.invalidArgument(error.localizedDescription)`.

## 3. Risks and mitigations

| Risk | Likelihood | Mitigation |
|------|-----------|------------|
| `ByteCountFormatter` has no `locale` property on macOS | High (confirmed) | Store locale in wrapper but don't apply it; tests compare against a reference formatter |
| `TimeZone(secondsFromGMT:)` returns optional on macOS 26 SDK | High | Use `TimeZone.gmt` (macOS 13+, non-optional) in tests |
| `AsyncSequence<Element, Failure>` generic unavailable on macOS 14 | High | Return `AsyncThrowingStream<Output, any Error>` (Session 01 precedent) |
| `GlobMatcher` cyclomatic complexity triggers SwiftLint | Medium | Split into `matchComponents` (outer) + `matchSegmentChars` (inner); each stays under 12 paths |
| `ThrottleState` actor isolation causes Swift 6 sendability errors | Medium | `Element: Sendable` constraint on extension; actor methods are `async` |
| `withProgress` semantic ambiguity (item count vs. bytes) | Medium | Document in source comments and handoff under "Non-obvious invariants" |
| `FileItemFilter` closure capture triggers Swift 6 warning | Low | Declare predicate as `@Sendable (FileItem) -> Bool`; all built-ins capture only `Sendable` values |
| `FilePath.relative(to:)` nil/empty distinction confusing to callers | Low | Document with explicit comment in source; repeat in handoff |
| SwiftFormat `--lint` argument order bug (Session 01) | Known | Pass paths first: `swiftformat <paths> --lint`, not `swiftformat --lint <paths>` |
| Trailing comma config drift between SwiftFormat and SwiftLint | Known (fixed) | `.swiftlint.yml` already has `trailing_comma: mandatory_comma: true` |
| Test file basename collision (Session 01 lesson) | Known (mitigated) | All test files have unique basenames: `PathUtilitiesTests.swift`, etc. |

## 7. Non-obvious invariants (must appear in handoff)

1. `FilePath.relative(to:)` returns `[]` (not `nil`) when `self == base`. `nil`
   means base is not a prefix or schemes differ.
2. `withProgress.bytesDone` carries **item counts**, not bytes, when the
   upstream element is not `FileItem` or `sizeInBytes` is `nil`. Callers must
   interpret `Progress` fields relative to their data source.
3. `ByteSizeFormatter.locale` is stored but **not applied** to the underlying
   `ByteCountFormatter` (API not available on macOS). Future work: post-process
   via `NumberFormatter`.
4. Glob patterns **without `/`** are internally prefixed with `**/`;
   patterns **with `/`** are matched as-is. This is an ergonomic choice, not a
   standard — document it clearly.
5. `FilePath.displayName` returns `"scheme:/"` for root paths (e.g., `"sftp:/"`),
   while `FileItem.displayName` returns `"/"` for root items. Different callers,
   different semantics.
6. `StevedoreErrorBridge` lives in `Result+Helpers.swift` (not
   `Sources/Core/Errors/`) to stay strictly within the session touch-glob.
