## Architecture Decision: Dependency Graph

The central constraint is **no circular dependencies**. `UIMenus` must not import `MainWindow`
(where `PaneSession` lives), and `MainWindow` may import `UIMenus`.

```
Core ← UIMenus ← MainWindow ← Stevedore (executable)
```

**Solution: Command Proxy Types in UIMenus**

`UIMenus` defines two `Sendable` structs that carry only what menus need:
- `PaneCommandProxy` — per-pane state + `@Sendable @MainActor` action closures
- `WindowCommandProxy` — window-level actions (show dialogs, switch tabs, etc.)

Both expose `FocusedValues` extensions via `@Entry`. `PaneHost` (MainWindow) constructs and
injects `PaneCommandProxy`. `MainWindowView` (MainWindow) constructs and injects `WindowCommandProxy`.
`AppCommands` (MainWindow) reads them via `@FocusedValue` and delegates to UIMenus sections.

`UIMenus` does **not** depend on ServicesSettings, UIConnectDialog, or any dialog module.

with SwiftUI's built-in `.cut`/`.copy`/`.paste` constants.

### `Sources/UI/Menus/OpenInTerminal.swift`

```swift
import AppKit
import Core

public enum OpenInTerminal {
    private static let knownBundles: [String] = [
        "com.apple.Terminal",
        "com.googlecode.iterm2",
        "dev.warp.Warp-Stable",
        "com.mitchellh.ghostty",
    ]

    /// Launches the preferred terminal at the given local path.
    /// Remote paths are silently ignored. Falls back to first installed known terminal.
    public static func launch(path: FilePath, using preferred: String) {
        guard path.scheme == .local else { return }
        let dirURL = URL(fileURLWithPath: path.posixString, isDirectory: true)
        let bundleID = preferred.isEmpty ? firstAvailableBundle() : preferred
        guard let bundleID,
              let appURL = NSWorkspace.shared.urlForApplication(withBundleIdentifier: bundleID)
        else { return }
        let config = NSWorkspace.OpenConfiguration()
        NSWorkspace.shared.open([dirURL], withApplicationAt: appURL, configuration: config)
    }

    private static func firstAvailableBundle() -> String? {
        knownBundles.first {
            NSWorkspace.shared.urlForApplication(withBundleIdentifier: $0) != nil
        }
    }
}
```

**Note**: `NSWorkspace.open(_:withApplicationAt:configuration:)` passes the directory URL as a
"document to open". Terminal.app and iTerm2 interpret this as `cd` to that directory. Warp and
Ghostty also handle it. Full AppleScript-based `do script "cd ..."` is out of scope.

### `Tests/UITests/MenusTests/ShortcutsTests.swift`

```swift
import UIMenus
import XCTest

final class ShortcutsTests: XCTestCase {
    /// Encode a KeyboardShortcut as a string for equality comparison.
    private func encode(_ s: KeyboardShortcut) -> String {
        "\(s.key.character)\(s.modifiers.rawValue)"
    }

    func testAllShortcutsAreUnique() {
        let all: [KeyboardShortcut] = [
            Shortcuts.newFile, Shortcuts.newFolder, Shortcuts.open, Shortcuts.moveToTrash,
            Shortcuts.find, Shortcuts.showHiddenFiles, Shortcuts.refresh,
            Shortcuts.goUp, Shortcuts.goBack, Shortcuts.goForward, Shortcuts.goHome,
            Shortcuts.connectToServer, Shortcuts.openInTerminal,
            Shortcuts.newTab, Shortcuts.closeTab, Shortcuts.reopenClosedTab,
        ]
        var seen: Set<String> = []
        for shortcut in all {
            let key = encode(shortcut)
            XCTAssertTrue(seen.insert(key).inserted,
                "Duplicate shortcut: \(key)")
        }
    }

    func testOpenInTerminalAndReopenClosedTabDontConflict() {
        XCTAssertNotEqual(
            encode(Shortcuts.openInTerminal),
            encode(Shortcuts.reopenClosedTab)
        )
    }

    func testNewTabAndOpenInTerminalDifferByModifiers() {
        // newTab = Cmd+T, openInTerminal = Cmd+Shift+T
        XCTAssertNotEqual(
            encode(Shortcuts.newTab),
            encode(Shortcuts.openInTerminal)
        )
    }
}
```

### `Sources/UI/MainWindow/PaneHost.swift`
Add `import UIMenus`. Build `PaneCommandProxy` from the session and inject via `.focusedValue`.
Extract into a private helper to avoid `function_parameter_count` lint violation:

```swift
import UIMenus

// In body:
VStack(...) { ... }
    .focusedValue(\.paneCommandProxy, isActive ? buildProxy() : nil)

// Private helper:
private func buildProxy() -> PaneCommandProxy {
    let sess = session
    return PaneCommandProxy(
        currentPath:     sess.currentPath,
        canGoBack:       sess.toolbarViewModel.canGoBack,
        canGoForward:    sess.toolbarViewModel.canGoForward,
        isRemoteReadOnly: sess.provider.scheme != .local,
        goBack:       { sess.toolbarViewModel.goBack() },
        goForward:    { sess.toolbarViewModel.goForward() },
        goUp:         { [p = sess.currentPath] in
                          let parent = FilePath(scheme: p.scheme, posix: (p.posix as NSString).deletingLastPathComponent)
                          sess.navigate(to: parent)
                      },
        goHome:       { sess.navigate(to: FilePath(scheme: .local, posix: NSHomeDirectory())) },
        goToComputer: { sess.navigate(to: FilePath(scheme: .local, posix: "/")) },
        newFolder: {}, newFile: {}, moveToTrash: {},
        toggleHiddenFiles: {},
        refresh: {},
        openInTerminal: { OpenInTerminal.launch(path: sess.currentPath, using: "Terminal") },
        openNewTab:      { sess.openTab(at: sess.currentPath) },
        closeActiveTab:  { if let id = sess.activeTabID { sess.closeTab(id) } },
        reopenClosedTab: {},
        nextTab:         {
            guard let cur = sess.activeTabID,
                  let idx = sess.tabs.firstIndex(where: { $0.id == cur }),
                  idx + 1 < sess.tabs.count else { return }
            sess.activateTab(sess.tabs[idx + 1].id)
        },
        previousTab:     {
            guard let cur = sess.activeTabID,
                  let idx = sess.tabs.firstIndex(where: { $0.id == cur }),
                  idx > 0 else { return }
            sess.activateTab(sess.tabs[idx - 1].id)
        },
        selectAll: {}
    )
}
```

## Design Decisions

| Decision | Rationale |
|----------|-----------|
| Proxy structs in `UIMenus`, not `MainWindow` | Breaks the `UIMenus ↔ MainWindow` circular dep; both proxies contain only `Core.FilePath` + closures |
| `@Entry` for `FocusedValues` | Cleaner than manual `FocusedValueKey` boilerplate; available macOS 14+ (deployment target) |
| `@Sendable @MainActor` closures | Swift 6 strict concurrency: all closures capture `@MainActor`-isolated types; explicit annotation prevents implicit `Sendable` inference warnings |
| Keep `AppCommands.swift` in `MainWindow` | Avoids moving the file; wires UIMenus sections without the circular dep problem |
| Stubs for file-op commands | UIPane (Session 16) is unimplemented; wiring the menu items now without full impl is correct — Session 16 will replace the stubs |
| `CommandGroup(replacing: .newItem)` for File | Prevents system "New" shortcut (⌘N) from appearing alongside our "New File" (⌘N) |
| `CommandGroup(after: .pasteboard)` for Find | Adds Find without removing system Cut/Copy/Paste/SelectAll |
| `CommandGroup(after: .windowSize)` for tabs | Places tab commands in the standard Window menu after existing system items |

## Risks and Mitigations

| Risk | Mitigation |
|------|-----------|
| `FilePath` has no `.parent` property | Use `(posix as NSString).deletingLastPathComponent`; verify by grep before coding |
| `KeyEquivalent("\u{7F}")` not accepted for Delete key | Alternative: `KeyEquivalent.delete` if it exists on macOS 14; test both |
| `@Entry` not available in current SDK | Fallback: manual `FocusedValueKey` struct + `FocusedValues` extension |
| `@FocusedValue` not re-evaluating after pane switch | Proxy injected in `PaneHost.body`; `@Observable` PaneSession drives re-render; should propagate automatically |
| `function_parameter_count` SwiftLint violation in `buildProxy()` | Extract into `buildNavigationActions()`, `buildTabActions()`, etc. sub-helpers |
| `StubCredentialStore`/`StubRemoteConnector` don't exist | Use inline `Text("Coming soon")` sheet body and skip real ConnectDialog for this session |
| `UISyncDialog`/`UIRenameDialog` are stubs | Confirmed — use `Text("Coming soon")` sheets, note in handoff |
| `swiftlint --strict --path <dir>` is INVALID | Per cerebrum: correct is `swiftlint --strict Sources/UI/Menus` (positional args) |
| `swiftformat --lint Sources/... ` wrong order | Per cerebrum: paths BEFORE `--lint`: `swiftformat Sources/UI/Menus Tests/UITests/MenusTests --lint` |
