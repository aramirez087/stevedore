## 3. Key design decisions

### 3.1 Module dependency DAG (this session)

```
Core
  ├── FileSystemLocal
  ├── FileSystemRemote      (+ Citadel, SotoS3)
  ├── FileSystemArchive     (+ ZIPFoundation)
  ├── ServicesCredentials
  ├── ServicesSettings
  ├── ServicesLogging       (+ swift-log)
  ├── FeaturesOperations
  ├── FeaturesSync
  ├── FeaturesRename
  ├── FeaturesPreview
  ├── FeaturesGit
  ├── FeaturesUninstaller
  ├── DesignSystem
  ├── UIPane
  ├── UITabs
  ├── UISidebar
  ├── UIToolbar
  ├── UITransfers
  ├── UISyncDialog
  ├── UIRenameDialog
  ├── UIConnectDialog
  ├── UISettingsUI
  ├── UIUninstallerUI
  ├── UIMenus
  └── MainWindow

Stevedore (executable) → Core, MainWindow
```

Rationale: Session 01 keeps every leaf module pointing only at `Core`. Cross-
module deps (e.g. UIPane → DesignSystem) belong to the session that introduces
the consuming code; introducing them now would force a Package.swift edit in a
later session, violating the "Package.swift frozen after Session 01" rule.

### 3.2 Concurrency model

- **Actors** own mutable state with I/O affinity: provider implementations,
  the operation queue, remote sessions, the keychain store, the ring-buffer
  logger.
- **Structured concurrency** (`async let`, `TaskGroup`, `AsyncStream`) for
  cancellable streaming work — directory enumeration, FSEvents, sync
  comparison.
- **`@MainActor`** for SwiftUI view-models (declared in downstream UI
  sessions, but the protocols here must compose with main-actor bindings).
- **All public types `Sendable`**. `Codable` value types are auto-Sendable;
  reference types are `final` and explicit. No `@unchecked Sendable` in this
  session.
- Callbacks use `@Sendable` closures; long-running observation uses
  `AsyncStream` rather than delegate patterns.

### 3.3 Protocol surface (signatures to materialize)

The protocols below are the complete public surface for Session 01. Downstream
sessions extend implementations but should not need to widen these protocols —
if they do, that signals a design miss to record in the handoff.

```swift
// FileSystemProvider — root abstraction for any file source.
public protocol FileSystemProvider: Sendable {
    var scheme: ConnectionScheme { get }
    func attributes(at path: FilePath) async throws -> FileAttributes
    func enumerate(at path: FilePath, options: EnumerationOptions) -> any FileEnumeration
    func execute(_ op: OperationDescriptor,
                 progress: OperationProgressReporting?) async throws -> OperationResult
    func watch(_ path: FilePath) -> AsyncStream<FilePathChange>
}

// FileEnumeration — AsyncSequence wrapper for lazy listing.
public protocol FileEnumeration: AsyncSequence, Sendable where Element == FileItem {}

// FileOperationExecutor — primitive op runner; queue/sync engines delegate here.
public protocol FileOperationExecutor: Sendable {
    func perform(_ op: OperationDescriptor,
                 progress: OperationProgressReporting?) async throws -> OperationResult
}

// OperationProgressReporting — callback type used by long-running ops.
public protocol OperationProgressReporting: Sendable {
    func report(_ progress: Progress) async
}

// CredentialStore — Keychain (or in-memory) facade.
public protocol CredentialStore: Sendable {
    func store(_ credential: Credential, for hostID: RemoteHostDescriptor.ID) async throws
    func credential(for hostID: RemoteHostDescriptor.ID) async throws -> Credential?
    func remove(for hostID: RemoteHostDescriptor.ID) async throws
    func list() async throws -> [RemoteHostDescriptor.ID]
}

// SettingsStore — typed settings + observation.
public protocol SettingsStore: Sendable {
    func value<Value: Codable & Sendable>(for setting: Setting<Value>) async -> Value
    func set<Value: Codable & Sendable>(_ value: Value, for setting: Setting<Value>) async
    func observe<Value: Codable & Sendable>(_ setting: Setting<Value>) -> AsyncStream<Value>
}

// AppLogger — uniform logging facade across the app.
public protocol AppLogger: Sendable {
    func log(_ level: LogLevel,
             _ message: @autoclosure @Sendable () -> String,
             category: LogCategory,
             metadata: [String: String]?,
             file: StaticString, line: UInt) async
}

// PreviewSource — Quick Look + first-party renderer entry point.
public protocol PreviewSource: Sendable {
    func thumbnail(for item: FileItem, size: CGSize) async throws -> Data?
    func preview(for item: FileItem) async throws -> PreviewPayload?
}

// GitStatusProvider — porcelain v2 wrapper.
public protocol GitStatusProvider: Sendable {
    func status(under directory: FilePath) async throws -> [GitFileStatus]
    func repositoryRoot(for path: FilePath) async -> FilePath?
}

// ArchiveBrowser — read entries from .zip / .tar / .tar.gz / .tar.bz2.
public protocol ArchiveBrowser: Sendable {
    func isArchive(_ path: FilePath) async -> Bool
    func entries(in archive: FilePath) async throws -> [FileItem]
}

// RemoteConnector — opens / tests a session for a given host.
public protocol RemoteConnector: Sendable {
    func test(_ host: RemoteHostDescriptor, credential: Credential?) async throws -> ConnectionTestResult
    func open(_ host: RemoteHostDescriptor, credential: Credential?) async throws -> any FileSystemProvider
}
```

Auxiliary support types live alongside in `Core/Types`:
`EnumerationOptions`, `OperationResult`, `FilePathChange`, `Credential`,
`Setting<Value>`, `LogLevel`, `LogCategory`, `PreviewPayload`,
`GitFileStatus`, `ConnectionTestResult`. Each is `Sendable`; Codable conformance
on those that persist (`Credential`, `Workspace`, `Tab`, `Bookmark`,
`RemoteHostDescriptor`, `OperationKind`).

### 3.4 Type design highlights

- **`FilePath`** is a value type wrapping a `ConnectionScheme` plus a normalized
  POSIX-style component array. Equatable, Hashable, Codable, Sendable. NOT
  `Foundation.FilePath` (different semantics for remote schemes).
- **`FileItem`** = `FilePath` + `FileAttributes` + `FileKind`. Lightweight
  value, Hashable for diffable lists.
- **`OperationKind`** is an enum: `.copy`, `.move`, `.delete`, `.rename`,
  `.mkdir`, `.symlink`, `.archive`, `.extract`, `.trash`. `OperationDescriptor`
  carries source(s), destination, kind, conflict policy reference.
- **`Progress`** is a struct (`bytesDone`, `bytesTotal?`, `phase`,
  `throughputBytesPerSecond?`). Distinct from `Foundation.Progress` — we want
  Sendable + Codable + ergonomic.
- **`StevedoreError`** is a tree of typed cases:
  `.fileSystem(FileSystemError)`, `.remote(RemoteError)`,
  `.archive(ArchiveError)`, `.credential(CredentialError)`,
  `.settings(SettingsError)`, `.cancelled`, `.invalidArgument(String)`,
  `.unsupported(String)`. Each leaf has a `LocalizedError` description and a
  `category: LogCategory` accessor for the logger.

### 3.5 Test fakes contract (Sources/Core/Testing)

Each fake must:

1. Conform to its declared protocol with no implementation gaps.
2. Be safe to construct on any actor (Sendable).
3. Provide an in-memory backing store with deterministic ordering.
4. Expose hooks tests need: e.g. `RecordingLogger.events: [LogEvent]`,
   `InMemoryFileSystemProvider.seed(_:)` to plant a tree.
5. Reset cleanly between tests (no shared module state).

Critical for parallelism: downstream sessions (UI, sync engine, operations
engine) write tests that depend on these fakes existing **today**. Insufficient
fake API == broken test bus across the epic.

### 3.6 Placeholder strategy

Every non-Core target ships exactly one `Placeholder.swift` with this shape:

```swift
import Core

/// Marker namespace replacing the placeholder once <ModuleName>'s real
/// implementation lands. Smoke tests assert the sentinel is reachable so the
/// module can be linked from downstream targets.
public enum <ModuleName>Module {
    public static let moduleName: String = "<ModuleName>"
}
```

This satisfies "stub that re-exports Core" (via `import Core`) without using
`@_exported`, which Swift discourages and makes downstream namespacing
ambiguous. It also gives smoke tests a concrete sentinel to check.

For modules that will later expose protocol-conforming services
(FileSystemLocal, ServicesCredentials, etc.), downstream sessions replace this
placeholder file with named files; the `Placeholder.swift` is deleted in those
sessions to keep the diff scoped.

## 4. Risks and mitigations

| # | Risk | Mitigation |
|---|------|------------|
| R1 | Citadel / Soto / ZIPFoundation latest versions may not resolve cleanly together on Swift 6.0 (transitive constraints, NIO version skew). | After writing source files, run `swift package resolve` first. If it fails, downgrade the failing dep to its latest compatible version, document the choice in `docs/architecture.md` §8 and the handoff. |
| R2 | Strict-concurrency (`complete`) may surface Sendable warnings on third-party SPI even though our own code is clean. | Wrap third-party imports inside files that don't yet expose any API in Session 01 (only the Placeholder.swift in `FileSystemRemote` / `FileSystemArchive` / `ServicesLogging`). Real surface lands in downstream sessions where they own the fix. |
| R3 | `swift build -warnings-as-errors` over the whole package can fail because of transitive warnings inside Citadel or Soto. | Do not pass `-warnings-as-errors` on default `swift build`. Use it as a separate gate (per the README) and, if upstream warnings leak, file in handoff "Open issues" — do not hack our targets to compensate. |
| R4 | macOS 14 deployment target with `Citadel`'s `MultipartUploadOptions` / NIO transitive Swift 6 conformance. | Mitigation R1 covers it. As a fallback, we can keep the dep declared but mark the FileSystemRemote target's deps inactive in this session by leaving Placeholder.swift content free of Citadel symbols. |
| R5 | `swiftlint --strict` may reject the auto-generated Package.swift because of `enableExperimentalFeature` keyword usage style. | Lint includes `Package.swift`, so we run lint locally and adjust formatting (trailing whitespace, spacing) before commit. The lint config is authoritative — never weakened. |
| R6 | Test targets that import several library targets but only use one of them risk compile errors when downstream modules add their own surface. | Smoke tests import each module separately and only touch the module's `<ModuleName>Module.moduleName` sentinel. No cross-module assumptions. |
| R7 | Empty `WindowGroup { EmptyView() }` may produce a runtime warning on macOS 14 about empty scene content. | Use a `Color.clear.frame(minWidth: 800, minHeight: 600)` instead of `EmptyView()`; this is acceptable per the spec ("empty window"). |
| R8 | Codable round-trip tests can break compilation if a Codable property type isn't itself Codable (e.g., `URL` for symlinks vs string). | Keep persisted types using primitive Swift types (`String`, `Int64`, `Date`, `[String]`, `enum`). Cross-check each type's properties before declaring `Codable`. |
| R9 | Placing `Codable` on enums with associated values requires hand-rolled coding when cases are non-trivial (e.g. `OperationKind.archive(format:)`). | Use `@frozen` only where stable; hand-roll Codable on enums with associated values, with explicit `CodingKeys` and a `kind` discriminator field. Cover with round-trip tests. |
| R10 | Smoke tests for UI-only targets may need `import SwiftUI` and only run on macOS — fine because we target only macOS, but `XCTSkipIf` may be needed if XCTest invoked for non-mac platforms. | Tests target macOS via Package platforms; `swift test` on Linux is not supported by this package. No skip needed. |
| R11 | `docs/roadmap/stevedore-mvp/` does not exist; creating it must be in-scope of the session even though the `touches:` glob list does not explicitly enumerate it. | The handoff file is universally required by operator rules; treat `docs/roadmap/stevedore-mvp/**` as an implicit allowed write path. Log the directory creation in the handoff. |
