#### `WindowState.swift`

`@MainActor @Observable` class. Mutable window arrangement; `WindowStateSnapshot` is the
`Codable, Sendable` value used for persistence and test round-trips.

**Design rationale for omitting `selectedSidebarItem` from `WindowStateSnapshot`**:
`SidebarItemID` (in `UISidebar`) is not `Codable`. Adding a retroactive `Codable` conformance
from `MainWindow` would be fragile. Sidebar selection is ephemeral — it is not persisted.

```swift
import Core
import Foundation
import UISidebar

@MainActor
@Observable
public final class WindowState {
    public var splitFraction: Double
    public var activePaneID: PaneID
    public var selectedSidebarItem: SidebarItemID?

    public static let minFraction = 0.2
    public static let maxFraction = 0.8

    public init(snapshot: WindowStateSnapshot = .default) {
        self.splitFraction = max(Self.minFraction, min(Self.maxFraction, snapshot.splitFraction))
        self.activePaneID = .left
    }
}

public struct WindowStateSnapshot: Codable, Sendable, Equatable {
    public var splitFraction: Double
    public var leftTabs: [Tab]
    public var leftActiveTabID: Tab.ID?
    public var rightTabs: [Tab]
    public var rightActiveTabID: Tab.ID?

    public static let `default` = WindowStateSnapshot(
        splitFraction: 0.5,
        leftTabs: [],
        leftActiveTabID: nil,
        rightTabs: [],
        rightActiveTabID: nil
    )
}
```

#### `PaneSession.swift`

`@MainActor @Observable` per-pane view model. Routing rule (from Session 19 CRITICAL contract):
**all navigations go through `toolbarViewModel.navigate(to:)`** to keep back/forward history in
sync. External callers use `PaneSession.navigate(to:)` which delegates to the toolbar.

**Reentrancy safety**: `toolbarViewModel.onNavigate` calls the private `updatePath(to:)` method,
which updates `PaneSession.currentPath` WITHOUT calling back the toolbar — preventing the
`navigate → onNavigate → navigate` infinite loop.

```swift
import Core
import Observation
import UIToolbar

@MainActor
@Observable
public final class PaneSession {
    public let id: PaneID
    public private(set) var currentPath: FilePath
    public private(set) var tabs: [Tab]
    public private(set) var activeTabID: Tab.ID?

    @ObservationIgnored public let provider: any FileSystemProvider
    @ObservationIgnored public let toolbarViewModel: PaneToolbarViewModel

    public init(id: PaneID, initialPath: FilePath, provider: any FileSystemProvider) {
        self.id = id
        self.currentPath = initialPath
        self.provider = provider
        let firstTab = Tab(path: initialPath)
        self.tabs = [firstTab]
        self.activeTabID = firstTab.id
        self.toolbarViewModel = PaneToolbarViewModel(initialPath: initialPath)
        // Reentrancy-safe: updatePath does NOT call toolbar back.
        self.toolbarViewModel.onNavigate = { [weak self] path in
            self?.updatePath(to: path)
        }
    }

    /// All external navigations (sidebar, double-click, etc.) route through here.
    public func navigate(to path: FilePath) {
        toolbarViewModel.navigate(to: path)
    }

    public func openTab(at path: FilePath) {
        let tab = Tab(path: path)
        tabs.append(tab)
        activateTab(tab.id)
    }

    public func closeTab(_ tabID: Tab.ID) {
        guard tabs.count > 1 else { return }
        tabs.removeAll { $0.id == tabID }
        if activeTabID == tabID {
            activeTabID = tabs.last?.id
            if let path = tabs.last?.path { toolbarViewModel.navigate(to: path) }
        }
    }

    public func activateTab(_ tabID: Tab.ID) {
        guard let tab = tabs.first(where: { $0.id == tabID }) else { return }
        activeTabID = tabID
        navigate(to: tab.path)
    }

    // Called only from toolbarViewModel.onNavigate — does NOT call toolbar back.
    private func updatePath(to path: FilePath) {
        currentPath = path
        if let idx = tabs.firstIndex(where: { $0.id == activeTabID }) {
            tabs[idx] = Tab(id: tabs[idx].id, path: path, title: tabs[idx].title)
        }
    }
}
```

#### `DualPaneLayout.swift`

Custom horizontal split that exposes a `@Binding var splitFraction` (clamped to
`WindowState.minFraction ... WindowState.maxFraction`). Uses `GeometryReader` to compute pixel
widths; `DragGesture` on an 8-pt transparent strip updates the fraction.

`HSplitView` (AppKit `NSSplitView`) is intentionally NOT used here: it manages its own divider
position internally and does not expose a binding, making round-trip persistence via
`WindowState` impossible.

```swift
import DesignSystem
import SwiftUI

public struct DualPaneLayout<Left: View, Right: View>: View {
    @Binding var splitFraction: Double
    var left: Left
    var right: Right

    public init(
        splitFraction: Binding<Double>,
        @ViewBuilder left: () -> Left,
        @ViewBuilder right: () -> Right
    ) { ... }

    public var body: some View {
        GeometryReader { geo in
            HStack(spacing: 0) {
                left.frame(width: leftWidth(in: geo.size.width))
                PaneDividerStrip(splitFraction: $splitFraction, totalWidth: geo.size.width)
                right.frame(maxWidth: .infinity)
            }
        }
    }

    private func leftWidth(in total: CGFloat) -> CGFloat {
        let f = max(WindowState.minFraction, min(WindowState.maxFraction, splitFraction))
        return total * f - 4  // 4 pt leaves room for the 8-pt divider strip
    }
}

private struct PaneDividerStrip: View {
    @Binding var splitFraction: Double
    let totalWidth: CGFloat

    var body: some View {
        Rectangle()
            .fill(Color.primary.opacity(0.12))
            .frame(width: 8)
            .gesture(
                DragGesture()
                    .onChanged { value in
                        let raw = Double((value.location.x + totalWidth * splitFraction) / totalWidth)
                        splitFraction = max(WindowState.minFraction,
                                            min(WindowState.maxFraction, raw))
                    }
            )
            .onHover { inside in
                if inside { NSCursor.resizeLeftRight.push() } else { NSCursor.pop() }
            }
    }
}
```

#### `MainWindowModel.swift`

`@MainActor @Observable` class that owns all window state. Constructed by `AppEnvironment` and
passed to `MainWindowView`. Persists window state via `WorkspacesRepository`.

**`activeOperations` pattern**: Since `FileOperationQueue.operationStream()` is async, we cannot
compute `activeOperations` synchronously. Instead `MainWindowModel` starts an observation `Task`
in `startObserving()` (called from `restore()`) and stores the current operations snapshot in a
published property `var activeOperations: [FeaturesOperations.Operation] = []`.

```swift
import Core
import FeaturesOperations
import Foundation
import Observation
import ServicesSettings
import UISidebar

@MainActor
@Observable
public final class MainWindowModel {
    public let operationQueue: FileOperationQueue
    public let sidebarViewModel: SidebarViewModel
    public let windowState: WindowState
    public let leftSession: PaneSession
    public let rightSession: PaneSession
    public private(set) var activeOperations: [FeaturesOperations.Operation] = []

    @ObservationIgnored private let repository: WorkspacesRepository?
    @ObservationIgnored private var streamTask: Task<Void, Never>?

    public var activePaneSession: PaneSession {
        windowState.activePaneID == .left ? leftSession : rightSession
    }

    public init(
        operationQueue: FileOperationQueue,
        sidebarViewModel: SidebarViewModel,
        windowState: WindowState,
        leftSession: PaneSession,
        rightSession: PaneSession,
        repository: WorkspacesRepository? = nil
    ) { ... }

    deinit { streamTask?.cancel() }

    public func restore() async {
        startObserving()
        guard let repo = repository else { return }
        let workspaces = await repo.all()
        if let latest = workspaces.last { applySnapshot(from: latest) }
    }

    public func save() async throws {
        guard let repo = repository else { return }
        let workspace = buildWorkspace()
        try await repo.save([workspace])
    }

    /// Routes a drop of paths from the opposite pane as a copy.
    public func handleDrop(_ paths: [FilePath], onto targetID: PaneID) {
        let dest = (targetID == .left ? leftSession : rightSession).currentPath
        let descriptor = OperationDescriptor(
            kind: .copy(policy: .ask),
            sources: paths,
            destination: dest
        )
        Task { await operationQueue.enqueue(descriptor) }
    }

    private func startObserving() {
        guard streamTask == nil else { return }
        streamTask = Task { [weak self, queue = operationQueue] in
            for await ops in queue.operationStream() {
                guard let self else { break }
                self.activeOperations = ops
            }
        }
    }

    private func applySnapshot(from workspace: Workspace) { ... }
    private func buildWorkspace() -> Workspace { ... }
}
```

#### `MainWindowView.swift`

Top-level SwiftUI view. Uses `NavigationSplitView` for the sidebar column and a `VStack` for the
dual-pane area + optional transfers panel.

**Sidebar → active pane routing**: `.onChange(of: model.sidebarViewModel.selection)` maps
`SidebarItemID` cases to `FilePath` and calls `model.activePaneSession.navigate(to:)`.

```swift
import Core
import DesignSystem
import FeaturesOperations
import SwiftUI
import UISidebar

public struct MainWindowView: View {
    @Bindable var model: MainWindowModel

    public var body: some View {
        NavigationSplitView(columnVisibility: .constant(.all)) {
            Sidebar(viewModel: model.sidebarViewModel)
                .navigationSplitViewColumnWidth(min: 180, ideal: 220, max: 320)
        } detail: {
            VStack(spacing: 0) {
                dualPane
                if !model.activeOperations.isEmpty {
                    Divider()
                    TransfersPanel(operations: model.activeOperations)
                        .frame(height: 140)
                        .transition(.move(edge: .bottom))
                }
            }
        }
        .frame(minWidth: 800, minHeight: 500)
        .task { await model.restore() }
        .onChange(of: model.sidebarViewModel.selection, routeSidebarSelection)
    }

    private var dualPane: some View {
        DualPaneLayout(splitFraction: $model.windowState.splitFraction) {
            PaneHost(
                session: model.leftSession,
                isActive: model.windowState.activePaneID == .left,
                onActivate: { model.windowState.activePaneID = .left },
                onDropped: { model.handleDrop($0, onto: .left) }
            )
        } right: {
            PaneHost(
                session: model.rightSession,
                isActive: model.windowState.activePaneID == .right,
                onActivate: { model.windowState.activePaneID = .right },
                onDropped: { model.handleDrop($0, onto: .right) }
            )
        }
    }

    private func routeSidebarSelection(_ old: SidebarItemID?, _ new: SidebarItemID?) {
        guard let id = new, let path = filePath(for: id) else { return }
        model.activePaneSession.navigate(to: path)
    }

    /// Maps sidebar items to navigable FilePaths.
    private func filePath(for id: SidebarItemID) -> FilePath? {
        switch id {
        case .volume(let url): return FilePath(scheme: .local, posix: url.path)
        case .bookmark(let bookmarkID):
            return model.sidebarViewModel.bookmarks.bookmarks
                .first { $0.id == bookmarkID }
                .map { FilePath(scheme: .local, posix: $0.path.posixString) }
        default: return nil
        }
    }
}
```

## 3. Design Decisions and Rationale

| Decision | Rationale |
|----------|-----------|
| `AppCommands` in `Sources/UI/MainWindow/` | `Sources/UI/Menus/` is outside the touch glob; the stub lives here temporarily. Session 27 may move/extend it. |
| UIPane/UITabs/UITransfers NOT imported by `MainWindow` | Those modules are still stubs; importing them would create dead imports. Inline placeholder views provide the needed visual structure. |
| ALL navigations route through `toolbarViewModel.navigate(to:)` | Session 19 CRITICAL contract: "all external navigations must go through vm.navigate(to:) to keep history in sync." Never write directly to `PaneSession.currentPath`. |
| `onNavigate` calls `updatePath(to:)` not `navigate(to:)` | Breaks the `navigate → onNavigate → navigate` infinite loop. The private `updatePath` updates state without calling toolbar back. |
| `WindowStateSnapshot` omits `selectedSidebarItem` | `SidebarItemID` is not `Codable`; retroactive conformance from `MainWindow` would be fragile. Sidebar selection is ephemeral. |
| `@ObservationIgnored` on injected reference-type deps in `@Observable` classes | Prevents Swift 6 non-`Sendable` warnings when macro wraps protocol existentials (learned in Session 18). |
| `JSONFileStore.init` wrapped in `try?` in `AppEnvironment` | The init is `throws`; graceful fallback (in-memory only) is safer than crashing on first launch. |
| `MainWindowModel` holds `WorkspacesRepository?` as optional | Allows test construction without a real on-disk repository. |
| Custom `DualPaneLayout` with `GeometryReader` + `DragGesture` instead of `HSplitView` | `HSplitView` (NSSplitView) does not expose a split-position binding; a custom divider with `@Binding var splitFraction` enables the persistence required by `WindowState`. |
| Concrete adapters live in `App/Stevedore/AppEnvironment.swift` | They import both `FileSystemLocal` and `UISidebar`. Placing them in the `MainWindow` library would violate the architectural principle that UI library modules depend only on `Core` protocols, not concrete service implementations. |
| `activeOperations` driven by async stream + `@Observable` stored property | `FileOperationQueue.operationStream()` is async; a stored property updated from a background `Task` is the correct `@Observable` pattern to expose a synchronous view into async state. |

## 4. Risks and Mitigations

| Risk | Mitigation |
|------|-----------|
| `xcodebuild -scheme Stevedore` quality gate may fail — no Xcode project exists in the repo | Operator rules say the Xcode project is "generated, never hand-edited". For the quality gate, use `swift build` as the authoritative build check. If `xcodebuild` is required, note that the scheme must be generated by opening `Package.swift` in Xcode first. Document this in the handoff under Open Issues. |
| `VolumeDiscovery` public API — anatomy shows it's an actor but does not list specific public methods | **Before implementing `VolumeDiscoveryAdaptor`**: read `Sources/FileSystem/Local/VolumeDiscovery.swift` in full. Map its `Volume` struct fields to `SidebarVolume` (url, name, isEjectable, isBoot) and event cases to `SidebarVolumeEvent`. |
| `OperationDescriptor.init` signature unknown | Read `Sources/Core/Types/OperationDescriptor.swift` before writing `handleDrop`. The anatomy shows it has `kind: OperationKind`, `sources: [FilePath]`, `destination: FilePath?`, `id: UUID`. Use `OperationDescriptor(kind: .copy(policy: .ask), sources: paths, destination: dest)`. |
| `FileOperationQueue` has no synchronous snapshot | Maintain `activeOperations: [FeaturesOperations.Operation]` property on `MainWindowModel`, updated from `operationQueue.operationStream()` via a background task started in `startObserving()`. |
| `BookmarksProviding.bookmarks` is synchronous but `BookmarksRepository.all()` is async | `BookmarksProviderAdapter` caches `[Bookmark]` in-memory. On init, starts `Task { self.bookmarks = await repo.all() }` (main-actor safe). On `add`/`remove`/`move`, mutates cache immediately (optimistic) and persists async with `try?`. |
| Swift 6 strict concurrency on `any FileSystemProvider` stored in `@Observable` class | Use `@ObservationIgnored` on the `provider` property in `PaneSession` to prevent macro from wrapping a non-observable protocol existential. |
| `MainWindowView.onChange(of:)` API — may need two-parameter form in newer SDK | Use `.onChange(of: model.sidebarViewModel.selection) { old, new in ... }` (Swift 5.9+ two-parameter form). Fall back to single-parameter form if building on older SDK. |
| `FilePath(scheme:posix:)` for bookmark paths — `Bookmark.path` is `FilePath` not `String` | Adjust `filePath(for:)` accordingly. `Bookmark.path.posixString` or direct use of the `FilePath` value. |
