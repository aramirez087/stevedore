# Session 17 Implementation Plan — Tabs View

## Overview

Build the per-pane tab strip: `TabStripViewModel` (view-model), `TabStrip` (container view),
`TabItemView` (per-tab cell), `TabContextMenu` (context-menu modifier), and `TabReorder`
(drag-and-drop reorder support). No dependency on Settings or any filesystem provider.

## Package.swift Change (Required Prerequisite)

The `UITabs` target currently has no `extraDependencies`. Add `DesignSystem`:

```swift
// Before
LibraryModule(name: "UITabs", path: "Sources/UI/Tabs", extraDependencies: []),

// After
LibraryModule(
    name: "UITabs",
    path: "Sources/UI/Tabs",
    extraDependencies: [.target(name: "DesignSystem")],
),
```

**Rationale**: The session instruction says "Use only `DesignSystem` tokens" and "Use `import Core`,
`import DesignSystem`". Without this change, `swift build --target UITabs` fails on any
`import DesignSystem` statement. This is an internal module dependency, not a new third-party
package — it does not violate the "Package.swift frozen for third-party packages" constraint from
session 01. Document the deviation in the handoff.

## Detailed Design

### 1. `TabStripViewModel.swift`

```
imports (sorted): Core, Observation
```

```swift
@MainActor
@Observable
public final class TabStripViewModel {
    public private(set) var tabs: [Tab]
    public private(set) var selectedTabID: Tab.ID?
    public private(set) var pinnedTabIDs: Set<Tab.ID>

    private var recentlyClosed: [Tab] = []
    private let maxRecentlyClosed = 10

    /// Called after every mutation. Host wires this to WorkspacesRepository.
    public var onChange: (([Tab], Tab.ID?) -> Void)?

    public init(tabs: [Tab] = [], selectedTabID: Tab.ID? = nil) {
        self.tabs = tabs
        self.selectedTabID = selectedTabID ?? tabs.first?.id
        self.pinnedTabIDs = []
    }

    // MARK: – Mutations

    public func open(_ tab: Tab)                      // append + select
    public func close(id: Tab.ID)                     // push to recentlyClosed, update selection
    public func select(id: Tab.ID)                    // no-op if id not in tabs
    public func reorder(fromOffsets: IndexSet, toOffset: Int)  // Array.move(fromOffsets:toOffset:)
    public func closeOthers(keeping id: Tab.ID)       // removes non-pinned tabs != id
    public func closeToRight(of id: Tab.ID)           // removes non-pinned tabs after id
    public func duplicate(id: Tab.ID)                 // inserts copy after original, selects copy
    public func togglePin(id: Tab.ID)                 // insert/remove from pinnedTabIDs
    public func reopenLastClosed()                    // pops recentlyClosed, calls open(_:)

    // MARK: – Derived

    public var hasRecentlyClosed: Bool                // !recentlyClosed.isEmpty

    // MARK: – Private

    private func notifyChange()                       // calls onChange?(tabs, selectedTabID)
}
```

**Key invariants:**
- `reorder` uses `Array.move(fromOffsets:toOffset:)` (macOS 14+); `selectedTabID` is stable
  across reorders because identity is by UUID, not index.
- `close` selects the tab at the same index after removal, or the last tab, or `nil`.
- `closeOthers` and `closeToRight` skip pinned tabs.
- `recentlyClosed` is capped at 10; oldest entries dropped from the front when exceeded.
- `open` always selects the newly opened tab.

**Concurrency:** All mutations are `@MainActor`-isolated. `onChange` closure is stored and called
on the main actor — no `@Sendable` annotation needed since it never crosses actor boundaries.

### 2. `TabItemView.swift`

```
imports (sorted): Core, DesignSystem, SwiftUI
```

```swift
public struct TabItemView: View {
    let tab: Tab
    let isSelected: Bool
    let isPinned: Bool       // drives pin icon + hides close button
    let isLoading: Bool      // triggers shimmer overlay
    let onSelect: () -> Void
    let onClose: () -> Void

    @Environment(\.theme) private var theme
    @State private var shimmerPhase: CGFloat = -1

    public var body: some View {
        HStack(spacing: Spacing.xs) {
            if isPinned {
                Image(systemName: "pin.fill")          // 9pt system font
                    .foregroundStyle(theme.colors.textSecondary)
            }
            Text(tab.title ?? tab.path.displayName)    // FilePath.displayName (session 02)
                .font(theme.typography.caption)
                .foregroundStyle(isSelected ? theme.colors.textPrimary : theme.colors.textSecondary)
                .lineLimit(1)
                .help(tab.path.posixString)            // full path as tooltip
            if !isPinned {
                Button(action: onClose) {
                    Image(systemName: "xmark").font(.system(size: 9))
                }
                .buttonStyle(.plain)
                .foregroundStyle(theme.colors.textSecondary)
            }
        }
        .padding(.horizontal, Spacing.sm)
        .padding(.vertical, Spacing.xs)
        .background {
            RoundedRectangle(cornerRadius: 6).fill(isSelected ? theme.colors.surface : Color.clear)
        }
        .overlay { if isLoading { shimmerOverlay } }
        .contentShape(Rectangle())
        .onTapGesture(perform: onSelect)
    }

    private var shimmerOverlay: some View {
        LinearGradient(
            colors: [Color.clear, theme.colors.surfaceElevated.opacity(0.5), Color.clear],
            startPoint: UnitPoint(x: shimmerPhase, y: 0.5),
            endPoint: UnitPoint(x: shimmerPhase + 1, y: 0.5)
        )
        .clipped()
        .onAppear {
            withAnimation(.linear(duration: 1.2).repeatForever(autoreverses: false)) {
                shimmerPhase = 1
            }
        }
    }
}
```

### 3. `TabContextMenu.swift`

```
imports (sorted): Core, SwiftUI
```

Implemented as a private `ViewModifier` exposed via a `View` extension to keep `TabItemView` clean.
The modifier is applied at the `TabStrip` `ForEach` level, not inside `TabItemView`.

```swift
public extension View {
    func tabContextMenu(tab: Tab, viewModel: TabStripViewModel) -> some View {
        modifier(TabContextMenuModifier(tab: tab, viewModel: viewModel))
    }
}

private struct TabContextMenuModifier: ViewModifier {
    let tab: Tab
    let viewModel: TabStripViewModel

    func body(content: Content) -> some View {
        content.contextMenu {
            Button("Close") { viewModel.close(id: tab.id) }
            Button("Close Others") { viewModel.closeOthers(keeping: tab.id) }
            Button("Close to the Right") { viewModel.closeToRight(of: tab.id) }
            Divider()
            Button("Duplicate") { viewModel.duplicate(id: tab.id) }
            Button(viewModel.pinnedTabIDs.contains(tab.id) ? "Unpin" : "Pin") {
                viewModel.togglePin(id: tab.id)
            }
            Divider()
            Button("Reopen Closed Tab") { viewModel.reopenLastClosed() }
                .disabled(!viewModel.hasRecentlyClosed)
        }
    }
}
```

**Swift 6 note:** Button actions run on main actor; `TabStripViewModel` is `@MainActor`; calling
its methods from button closures is valid without additional isolation annotations.

### 4. `TabReorder.swift`

```
imports (sorted): Core, SwiftUI, UniformTypeIdentifiers
```

```swift
extension UTType {
    static let stevedoreTabID = UTType(exportedAs: "com.stevedore.tab-id")
}

public extension View {
    func tabDragReorder(tab: Tab, viewModel: TabStripViewModel) -> some View {
        self
            .onDrag { NSItemProvider(object: tab.id.uuidString as NSString) }
            .onDrop(
                of: [.stevedoreTabID, .plainText],
                delegate: TabDropDelegate(targetTab: tab, viewModel: viewModel)
            )
    }
}

private struct TabDropDelegate: DropDelegate {
    let targetTab: Tab
    let viewModel: TabStripViewModel

    func dropUpdated(info: DropInfo) -> DropProposal? {
        DropProposal(operation: .move)
    }

    func performDrop(info: DropInfo) -> Bool {
        let providers = info.itemProviders(for: [.stevedoreTabID, .plainText])
        guard let provider = providers.first else { return false }
        provider.loadObject(ofClass: NSString.self) { object, _ in
            guard
                let idString = object as? String,
                let draggedID = UUID(uuidString: idString)
            else { return }
            Task { @MainActor in
                guard
                    let fromIdx = viewModel.tabs.firstIndex(where: { $0.id == draggedID }),
                    let toIdx = viewModel.tabs.firstIndex(where: { $0.id == targetTab.id }),
                    fromIdx != toIdx
                else { return }
                let toOffset = toIdx > fromIdx ? toIdx + 1 : toIdx
                viewModel.reorder(fromOffsets: IndexSet(integer: fromIdx), toOffset: toOffset)
            }
        }
        return true
    }
}
```

**UTType:** `UTType(exportedAs:)` is non-optional (no force-unwrap). No Info.plist registration
needed for within-app drag-and-drop. `.plainText` listed as fallback.

**Threading:** `NSItemProvider.loadObject` callback runs on an arbitrary queue. The
`Task { @MainActor in }` hop safely calls `viewModel.reorder()` on the main actor.

**Offset arithmetic:** `toOffset = toIdx > fromIdx ? toIdx + 1 : toIdx` matches `Array.move`
semantics (verified: moving forward requires +1 because the element is removed first).

### 5. `TabStrip.swift`

```
imports (sorted): Core, DesignSystem, SwiftUI
```

```swift
public struct TabStrip: View {
    var viewModel: TabStripViewModel         // @Observable: SwiftUI tracks automatically
    let loadingTabIDs: Set<Tab.ID>           // host passes which tabs are paginating
    let onNew: () -> Void                    // host decides what Tab to open (portable)

    @Environment(\.theme) private var theme

    public init(
        viewModel: TabStripViewModel,
        loadingTabIDs: Set<Tab.ID> = [],
        onNew: @escaping () -> Void
    )

    public var body: some View {
        HStack(spacing: 0) {
            // Leading "+" button (per session spec)
            Button(action: onNew) {
                Image(systemName: "plus")
                    .font(.system(size: 11))
                    .foregroundStyle(theme.colors.textSecondary)
            }
            .buttonStyle(.plain)
            .padding(.horizontal, Spacing.sm)

            Divider().padding(.vertical, Spacing.xs)

            // Scrollable tab list (horizontal overflow)
            ScrollView(.horizontal, showsIndicators: false) {
                HStack(spacing: 1) {
                    ForEach(viewModel.tabs) { tab in
                        TabItemView(
                            tab: tab,
                            isSelected: viewModel.selectedTabID == tab.id,
                            isPinned: viewModel.pinnedTabIDs.contains(tab.id),
                            isLoading: loadingTabIDs.contains(tab.id),
                            onSelect: { viewModel.select(id: tab.id) },
                            onClose: { viewModel.close(id: tab.id) }
                        )
                        .tabContextMenu(tab: tab, viewModel: viewModel)
                        .tabDragReorder(tab: tab, viewModel: viewModel)
                    }
                }
                .padding(.horizontal, Spacing.xs)
            }
        }
        .frame(height: 32)
        .background(theme.colors.background)
        .overlay(alignment: .bottom) { Divider() }
    }
}
```

## Key Design Decisions

| Decision | Rationale |
|---|---|
| `Package.swift`: add DesignSystem to UITabs | Session requires `import DesignSystem`; internal module dep, not third-party |
| `pinnedTabIDs: Set<Tab.ID>` in VM, not in `Tab` | Core's `Tab` struct (session 01) must not be modified; operator rule "don't touch other modules" |
| `onChange: (([Tab], Tab.ID?) -> Void)?` callback | Gives host exactly what it needs to persist; avoids coupling to any specific persistence layer |
| `Array.move(fromOffsets:toOffset:)` | Same API used by SwiftUI `List.onMove`; stable identity across reorder (UUID not index) |
| `UTType(exportedAs:)` for drag type | Non-optional; no Info.plist needed for within-app DnD; avoids `.plainText` ambiguity |
| `Task { @MainActor in }` in DropDelegate | Correct thread hop from NSItemProvider callback queue back to main actor |
| Context menu as private `ViewModifier` | Keeps `TabItemView` init clean; modifier applied at `TabStrip` ForEach level |
| Shimmer as `LinearGradient` animation | No third-party dependency; `@State shimmerPhase` with `.repeatForever` animation |
| `@Observable` (not `ObservableObject`) | macOS 14+ compatible; matches session spec; automatic change tracking |
| Reopen stack capped at 10 | Prevents unbounded memory growth |
| Test class named `TabsTests` | Required for `swift test --filter TabsTests` to match the class name substring |
| `Placeholder.swift` left unchanged | Preserves `UITabsModule.moduleName` sentinel tested by existing `UITabsSmokeTests` |

## Risks and Mitigations

| Risk | Mitigation |
|---|---|
| **Package.swift not in touches list** but DesignSystem import required | Document deviation in handoff; classify as internal dep, not frozen third-party |
| **Swift 6 strict concurrency** on `@Observable` class | `@MainActor final class` isolates all mutable state to main actor |
| **`DropDelegate.performDrop` callback** runs off main actor | `Task { @MainActor in viewModel.reorder(...) }` |
| **`UTType(exportedAs:)` within-app** without Info.plist | Valid for within-app DnD; acceptable that other apps cannot recognize the type |
| **`close` selection logic** when closing middle tab | Select tab at same index post-removal, fall back to last tab, then nil |
| **`reorder` offset arithmetic** (forward vs backward moves) | `toOffset = toIdx > fromIdx ? toIdx + 1 : toIdx` — verified against `Array.move` semantics |
| **Cyclomatic complexity** limit (12 warning) | All methods are simple branching; longest is `close` (~5 branches); `@ViewBuilder` bodies exempt |
| **SwiftLint `sorted_imports`** | Each file imports listed alphabetically; verify before committing |
| **`implicit_return` rule** | Use implicit return for single-expression getters; `body` is multi-statement and does not apply |
