# Session 23 Implementation Plan — Connect-to-Server Dialog

## Context

Build the `UIConnectDialog` module: a modal SwiftUI dialog for creating or editing remote
connections (SFTP, FTP, WebDAV, S3, SMB) with per-scheme field validation, test-connection
support via injected `RemoteConnector`, credential persistence via injected `CredentialStore`,
and host-provided save/connect callbacks. No Keychain or real network I/O in tests.

## Key Design Decisions

### 1. `@Observable` (not `ObservableObject`)

`@Observable` macro (Swift 5.9+ / macOS 14) with `@Bindable` in views. Avoids `@Published`
verbosity. All mutation occurs on `@MainActor`. Fully compatible with Swift 6 strict concurrency.

### 2. Protocol-only imports — no FileSystemRemote or ServicesCredentials

`UIConnectDialog` imports only `Core` + `DesignSystem`. `RemoteConnector` and `CredentialStore`
are Core protocols. This keeps compilation fast (no Citadel/Soto) and tests isolated.

The dialog is injected at call-site (by MainWindow, Session 26) with the concrete implementations:
```swift
ConnectDialog(viewModel: ConnectDialogViewModel(
    credentialStore: KeychainCredentialStore(),   // from ServicesCredentials
    connector: RemoteProviderRegistry.shared,      // from FileSystemRemote
    editing: nil
))
```

### 3. NSOpenPanel behind an injectable closure

```swift
public typealias KeyPickerHandler = @MainActor @Sendable () async -> URL?
```

`ConnectDialogViewModel.init` accepts `keyPickerHandler: KeyPickerHandler`. Default implementation
opens `NSOpenPanel` on the main actor. Tests inject a closure returning a pre-baked URL.

### 4. Stable UUID at init time

The UUID for `RemoteHostDescriptor.id` is generated once in `init()` and reused across all
`buildDescriptor()` calls (both save and connect). When editing an existing host, the existing
UUID is preserved. This keeps the credential store write and the descriptor consistent.

### 5. Validation: synchronous, populates error array

```swift
@discardableResult
public func validate() -> Bool
```

Populates `validationErrors: [ValidationError]`. Each `ValidationError` carries a `field:
ValidationErrorField` discriminator and `message: String`. Views render the message inline
below the offending field with `.accessibilityValue(error.message)`.

`ValidationErrorField` is a top-level enum (not nested) to satisfy SwiftLint's `nesting` rule.

### 6. Auth modes per scheme

```
sftp:   [.password, .sshKey]
ftp:    [.password, .anonymous]
webdav: [.password]
s3:     [.iam, .password]   // .password = access key + secret key
smb:    [.password]
```

When the user switches scheme, `authMode` resets to the first valid mode for the new scheme
if the current mode is not available (e.g., switching from SFTP with `.sshKey` to S3 → `.iam`).

### 7. S3 credential encoding

`CredentialMaterial` has no AWS-specific case (Session 06 decision). Encode S3 access key as:
```
CredentialMaterial.oauthToken("AKID:<accessKeyID>\nSECRET:<secretKey>")
```
IAM mode → pass `credential: nil` to `connector.test/open`; the remote provider uses ambient IAM.

The `awsAccessKeyID` and `awsSecretKey` are separate ViewModel properties so each can have its
own SecureField and validation error.

### 8. Port defaults

| Scheme | Default | Valid range |
|---|---|---|
| sftp | 22 | 1–65535 |
| ftp | 21 | 1–65535 |
| webdav | 443 | 1–65535 |
| smb | 445 | 1–65535 |
| s3 | — | — (no port) |

Port stored as `portString: String` (empty = use default). Validation converts to `Int?`;
rejects non-numeric or out-of-range.

### 9. SSH key file reading deferred to save time

`sshKeyFileURL: URL?` is stored in the ViewModel. The PEM content is read at `buildCredential()`
time via `String(contentsOf:)`, not at file-pick time. This avoids storing raw key material in
memory longer than necessary.

### 10. Test-connection failure messages: static strings only

`testConnection()` catch block:
```swift
} catch {
    // Never interpolate password, key material, or passphrase here
    testStatus = .failure(message: "Could not reach \(hostname) (\(selectedScheme.rawValue))")
}
```

`RedactionTests` verifies by injecting credentials containing a known sentinel ("REDACT-ME") and
asserting the sentinel is absent from every reachable `.failure(message:)` value.

### 11. swiftformat argument order (from cerebrum)

The quality gate in the session spec has `swiftformat --lint <paths>` — this is the broken form
(SwiftFormat 0.59 bug). Always use `swiftformat <paths> --lint`.

### 12. OSAllocatedUnfairLock in test fakes (from Session 04 + cerebrum)

`FakeRemoteConnector` is an `actor` (cleanest Sendable conformance). Accessing recorded call counts
from `@MainActor` test bodies uses `await`. No `NSLock` needed.

## ConnectDialogViewModel Public API

```swift
@MainActor
@Observable
public final class ConnectDialogViewModel {
    // Scheme
    public var selectedScheme: ConnectionScheme

    // Common fields
    public var displayName: String
    public var hostname: String
    public var portString: String        // "" = use default
    public var remotePath: String
    public var username: String

    // Auth
    public var authMode: AuthMode
    public var password: String
    public var showPassword: Bool        // never persisted
    public var sshKeyURL: URL?
    public var sshKeyPassphrase: String

    // S3-specific
    public var s3Bucket: String
    public var s3Region: String
    public var awsAccessKeyID: String
    public var awsSecretKey: String

    // State
    public var validationErrors: [ValidationError]
    public var testStatus: TestConnectionStatus
    public var isSaving: Bool

    // Callbacks (set by host before presenting)
    public var onSave: (@MainActor (RemoteHostDescriptor) -> Void)?
    public var onConnect: (@MainActor (RemoteHostDescriptor) -> Void)?
    public var onCancel: (@MainActor () -> Void)?

    // Init — create mode
    public init(
        credentialStore: any CredentialStore,
        connector: any RemoteConnector,
        keyPickerHandler: @escaping KeyPickerHandler = ConnectDialogViewModel.defaultKeyPickerHandler
    )

    // Init — edit mode
    public init(
        editing: RemoteHostDescriptor,
        credentialStore: any CredentialStore,
        connector: any RemoteConnector,
        keyPickerHandler: @escaping KeyPickerHandler = ConnectDialogViewModel.defaultKeyPickerHandler
    )

    // Static helpers
    public static func availableModes(for scheme: ConnectionScheme) -> [AuthMode]
    public static func defaultPort(for scheme: ConnectionScheme) -> Int?

    // Actions
    @discardableResult public func validate() -> Bool
    public func buildDescriptor() -> RemoteHostDescriptor
    public func buildCredential() throws -> Credential?
    public func testConnection() async
    public func save() async
    public func connect() async
    public func pickSSHKey() async
    public func cancel()
}
```

## Save / Connect Callback Contracts

```
save() flow:
  1. validate() → abort (return) if false
  2. buildDescriptor() → descriptor (stable UUID)
  3. buildCredential() → credential?
  4. if credential != nil: await credentialStore.store(credential!, for: descriptor.id)
  5. await onSave?(descriptor)

connect() flow:
  1–4. Same as save()
  5. await onSave?(descriptor)
  6. await onConnect?(descriptor)

cancel() flow:
  validationErrors.removeAll()
  await onCancel?()
```

IAM mode: `buildCredential()` returns `nil`; step 4 is skipped; connector receives `nil` credential
and uses ambient instance credentials.

## Validation Rules

| Field | Rule |
|---|---|
| `hostname` | Non-empty; no leading/trailing whitespace |
| `portString` | If non-empty: must parse as Int in 1…65535 |
| `username` | Required for SFTP/WebDAV/SMB (password auth); optional for FTP password; not needed for anonymous or IAM |
| `sshKeyURL` | Required when `authMode == .sshKey` |
| `awsAccessKeyID` | Required for S3 `.password` auth |
| `awsSecretKey` | Required for S3 `.password` auth |
| `s3Bucket` | Required for S3; non-empty |
| `s3Region` | Required for S3; non-empty |

## Form Schema per Scheme

### SFTP
- Display name (free text, bookmark label)
- Hostname (required)
- Port (optional, default 22)
- Remote path (optional, default "/")
- Username (required for password/sshKey)
- Auth: password (SecureField) | SSH key (file URL + passphrase SecureField)

### FTP
- Display name
- Hostname (required)
- Port (optional, default 21)
- Remote path (optional)
- Username (optional for anonymous)
- Auth: password | anonymous

### WebDAV
- Display name
- Hostname (required; WebDAV base path goes in Remote path)
- Port (optional, default 443)
- Remote path (optional)
- Username (required)
- Auth: password only

### S3
- Display name
- Custom endpoint / hostname (optional; empty = standard AWS)
- Region (required; Picker with static list)
- Bucket (required)
- Auth: IAM | access key (AccessKeyID + SecretKey SecureField)

### SMB
- Display name
- Hostname (required)
- Port (optional, default 445)
- Remote path (share + path, optional)
- Username (required)
- Auth: password only

## Risks and Mitigations

| Risk | Mitigation |
|---|---|
| Package.swift outside `touches:` | Minimal change; document in handoff |
| SwiftLint `nesting` for Field inside ValidationError | `ValidationErrorField` at file scope |
| `wrapMultilineStatementBraces` ↔ `opening_brace` conflict | `.swiftformat` already has `--disable wrapMultilineStatementBraces` (Session 04); use `let` bindings for multi-line conditions |
| `NSOpenPanel` in tests shows real UI | Injectable `KeyPickerHandler` closure — tests never call real panel |
| `@Observable` + `@MainActor` in tests | Mark all test classes `@MainActor`; async tests use `async throws` |
| SwiftLint cyclomatic complexity in `validate()` | Extract per-scheme sub-validators; each under 12 branches |
| swiftformat --lint arg order bug | Run `swiftformat <paths> --lint` (paths first) per cerebrum |
| S3 IAM: no credential to store | Detected by `authMode == .iam`; `buildCredential()` returns `nil`; store step skipped |
