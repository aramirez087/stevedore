connections (SFTP, FTP, WebDAV, S3, SMB) with per-scheme field validation, test-connection

## Key design decisions

### 1. `@Observable` (not ObservableObject)

`@Observable` macro (Swift 5.9+ / macOS 14) with `@Bindable` in views. No `@Published` verbosity.
All mutation on `@MainActor`. Fully Swift 6 strict-concurrency-compatible.

### 2. Protocol-only imports — no FileSystemRemote or ServicesCredentials

`UIConnectDialog` imports only `Core` + `DesignSystem`. `RemoteConnector` and `CredentialStore`
are Core protocols injected at call-site by Session 26 (MainWindow). This keeps compilation fast
(no Citadel/Soto transitive graph) and test setup minimal. SSH key PEM content is read from disk
as a `String(contentsOf:)` at `buildCredential()` time; format validation by Citadel at connect.

### 3. NSOpenPanel behind an injectable closure

```swift
public typealias KeyPickerHandler = @MainActor @Sendable () async -> URL?
```

`ConnectDialogViewModel.init` accepts `keyPickerHandler: KeyPickerHandler` with a default that
opens `NSOpenPanel` on the main actor. Tests inject a closure returning a pre-baked URL — no
panel appears in unit tests.

### 4. Stable UUID at init time

`id: UUID` is generated once in `init()` (or taken from `existingDescriptor.id`). All
`buildDescriptor()` calls return the same UUID. Credential store writes and descriptor callbacks
are always bound to the same identifier.

### 5. Validation: synchronous, populates error array

```swift
@discardableResult
public func validate() -> Bool
```

Populates `validationErrors: [ValidationError]`. Each `ValidationError` carries a `field:
ValidationErrorField` discriminator (top-level enum, not nested — SwiftLint `nesting` rule) and
a `message: String`. Form views render the message inline below the offending `TextField` /
`SecureField` and set `.accessibilityValue("Error: \(message)")`.

### 6. Auth modes per scheme

```
sftp:   [.password, .sshKey]
ftp:    [.password, .anonymous]
webdav: [.password]
s3:     [.iam, .password]   // .password = access key ID + secret key
smb:    [.password]
```

When the user switches scheme and the current `authMode` is not in the new scheme's valid set,
`authMode` resets to the first allowed mode. This is a computed property side-effect triggered
from the `selectedScheme` setter.

### 7. S3 credential encoding

`CredentialMaterial` has no AWS-specific case (Session 06 decision). Encode S3 access key as:
```
Credential(username: accessKeyID,
           material: .password(secretAccessKey))
```
IAM mode → `buildCredential()` returns `nil`; connector receives `nil` and uses ambient IAM.

### 8. Port storage and defaults

Port stored as `portString: String` (empty = use scheme default). `validate()` converts to `Int?`;
rejects non-numeric and out-of-range (1…65535).

| Scheme | Default port |
|---|---|
| sftp | 22 |
| ftp | 21 |
| webdav | 443 |
| smb | 445 |
| s3 | — |

### 9. Show-password toggle lives in ViewModel

`public var showPassword: Bool` stored on `ConnectDialogViewModel` — never persisted (ViewModel
lifetime is tied to the presented sheet). Toggling swaps between `SecureField` and `SDTextField`
in the form view. Lives in the ViewModel rather than the View so tests can verify the initial
state is `false` without needing SwiftUI rendering.

### 10. Test-connection failure messages: static strings only

Failure message is produced by a private static switch over `ConnectionTestResult.Status`. No
dynamic interpolation of credential-bearing values. The `RedactionTests` file injects known
sentinel strings ("REDACT-ME") into every credential field and asserts the sentinel is absent
from every reachable `TestConnectionStatus.failure(message:)` value.

```swift
private static func statusMessage(_ status: ConnectionTestResult.Status) -> String {
    switch status {
    case .success:              return "Connection successful."
    case .authenticationFailed: return "Authentication failed. Check your credentials."
    case .unreachable:          return "Server is unreachable. Check the hostname and port."
    case .timeout:              return "Connection timed out."
    case .unsupported:          return "This protocol is not supported."
    case .unknown:              return "An unknown error occurred."
    }
}
```

### 11. swiftformat argument order (cerebrum Key Learning)

The quality gate in the session spec reads `swiftformat --lint <paths>` — this is the broken form
(SwiftFormat 0.59 `--lint` as prefix). Always use `swiftformat <paths> --lint` (paths first).

### 12. swiftlint --path flag does not exist (cerebrum Do-Not-Repeat)

The session spec quality gate reads `swiftlint --strict --path Sources/UI/ConnectDialog`. The
`--path` flag is NOT valid for swiftlint. Correct form: `swiftlint --strict Sources/UI/ConnectDialog`
(positional path argument, no `--path`).

### 13. `@ObservationIgnored` on injected dependencies (cerebrum Decision Log)

All `any Protocol` stored properties — `connector`, `credentialStore`, `keyPickerHandler`, and
the callback closures — are annotated `@ObservationIgnored`. This prevents the `@Observable` macro
from wrapping protocol existentials in observation accessors, which would emit Swift 6 non-Sendable
warnings. Pattern established in Session 18 (`SidebarViewModel`).

### 14. `FakeRemoteConnector` as an `actor` (cerebrum — Session 04 pattern)

`actor` gives automatic `Sendable` conformance and thread-safe call recording without needing
`OSAllocatedUnfairLock`. Accessing `testCalls` in `@MainActor` test bodies uses `await`. No
`NSLock` needed.

## `ConnectDialogViewModel` public API

```swift
@MainActor
@Observable
public final class ConnectDialogViewModel {
    // MARK: - Scheme
    public var selectedScheme: ConnectionScheme

    // MARK: - Common fields
    public var displayName: String          // bookmark label; defaults to hostname
    public var hostname: String
    public var portString: String           // "" = use scheme default
    public var remotePath: String           // initial path

    // MARK: - Auth fields (all schemes share this flat layout)
    public var username: String
    public var authMode: AuthMode
    public var password: String
    public var showPassword: Bool           // never persisted
    public var sshKeyURL: URL?
    public var sshKeyPassphrase: String

    // MARK: - S3-specific
    public var s3Bucket: String
    public var s3Region: String
    public var awsAccessKeyID: String
    public var awsSecretKey: String

    // MARK: - State
    public private(set) var validationErrors: [ValidationError]
    public private(set) var testStatus: TestConnectionStatus
    public private(set) var isSaving: Bool

    // MARK: - Callbacks (host sets before presenting)
    public var onSave: (@MainActor (RemoteHostDescriptor) -> Void)?
    public var onConnect: (@MainActor (RemoteHostDescriptor) -> Void)?
    public var onCancel: (@MainActor () -> Void)?

    // MARK: - Init (create mode)
    public init(
        credentialStore: any CredentialStore,
        connector: any RemoteConnector,
        keyPickerHandler: @escaping KeyPickerHandler = ConnectDialogViewModel.defaultKeyPickerHandler
    )

    // MARK: - Init (edit mode)
    public init(
        editing: RemoteHostDescriptor,
        credentialStore: any CredentialStore,
        connector: any RemoteConnector,
        keyPickerHandler: @escaping KeyPickerHandler = ConnectDialogViewModel.defaultKeyPickerHandler
    )

    // MARK: - Static helpers
    public static func availableModes(for scheme: ConnectionScheme) -> [AuthMode]
    public static func defaultPort(for scheme: ConnectionScheme) -> Int?

    // MARK: - Actions
    @discardableResult public func validate() -> Bool
    public func buildDescriptor() -> RemoteHostDescriptor
    public func buildCredential() throws -> Credential?
    public func testConnection() async
    public func save() async
    public func connect() async
    public func pickSSHKey() async           // calls keyPickerHandler
    public func cancel()
}
```

## Save / connect callback contracts

```
save() flow:
  1. validate()                            → abort if false
  2. buildDescriptor()                     → descriptor (stable UUID)
  3. buildCredential()                     → credential? (nil for IAM / anonymous)
  4. if credential != nil:
         await credentialStore.store(credential!, for: descriptor.id)
  5. await onSave?(descriptor)

connect() flow:
  1–4. Same as save()
  5. await onSave?(descriptor)
  6. await onConnect?(descriptor)

cancel() flow:
  validationErrors.removeAll()
  await onCancel?()
```

IAM / anonymous: `buildCredential()` returns `nil`; step 4 is skipped; connector receives
`credential: nil`.

## Form schema per scheme

### SFTP
- Display name (optional; defaults to hostname)
- Hostname (required)
- Port (optional, default 22, 1–65535)
- Remote path (optional, default "/")
- Username (required for password + sshKey auth)
- Auth: password (SecureField + show toggle) | SSH key (file URL + optional passphrase)

### FTP
- Display name
- Hostname (required)
- Port (optional, default 21)
- Remote path (optional)
- Username (optional for anonymous)
- Auth: password | anonymous

### WebDAV
- Display name
- Hostname (required; full WebDAV base path in remote path)
- Port (optional, default 443)
- Remote path (optional)
- Username (required)
- Auth: password only

### S3
- Display name
- Custom endpoint (optional; empty = standard AWS)
- Region (required; Picker from static list)
- Bucket (required)
- Auth: IAM | access key (KeyID + SecretKey SecureField)

### SMB
- Display name
- Hostname (required)
- Port (optional, default 445)
- Remote path (share name + path, optional)
- Username (required)
- Auth: password only

## Validation rules

| Field | Condition for error |
|---|---|
| `hostname` | Empty or whitespace-only (all schemes except S3) |
| `portString` | Non-empty and not parseable as Int, or Int not in 1…65535 |
| `username` | Empty when authMode is `.password` or `.sshKey` for SFTP/WebDAV/SMB |
| `sshKeyURL` | Nil when `authMode == .sshKey` |
| `awsAccessKeyID` | Empty when S3 `authMode == .password` |
| `awsSecretKey` | Empty when S3 `authMode == .password` |
| `s3Bucket` | Empty (S3 only) |
| `s3Region` | Empty (S3 only) |

## Risks and mitigations

| Risk | Mitigation |
|---|---|
| `swiftlint --strict --path` is not valid (cerebrum Do-Not-Repeat) | Use `swiftlint --strict Sources/UI/ConnectDialog` (positional, no `--path`) |
| `swiftformat --lint <paths>` arg order (cerebrum Key Learning) | Always `swiftformat <paths> --lint` (paths before flag) |
| SwiftLint `nesting` for `ValidationErrorField` inside `ValidationError` | `ValidationErrorField` declared at file scope, not nested |
| `wrapMultilineStatementBraces` ↔ `opening_brace` conflict | `.swiftformat` already has `--disable wrapMultilineStatementBraces` (Session 04); extract multi-line bool conditions into `let` bindings |
| `NSOpenPanel` shows real UI in unit tests | `KeyPickerHandler` injectable closure — tests inject a closure returning a pre-baked URL |
| `@Observable` + `@MainActor` in tests | Mark all test classes `@MainActor`; all test methods `async throws` |
| SwiftLint cyclomatic complexity in `validate()` | Extract `validateSFTP()`, `validateFTP()` etc. private helpers; each ≤ 10 branches |
| S3 IAM → no credential to store | `authMode == .iam` detected in `buildCredential()` → returns `nil`; save() skips store step |
| `@Observable` + protocol existential Sendable warnings | All `any Protocol` properties `@ObservationIgnored` (SidebarViewModel pattern) |
| Retain cycle in testConnection Task | Capture `let connector = self.connector` (Sendable) before `Task { }` + `guard let self else { return }` inside (not before) task body |
