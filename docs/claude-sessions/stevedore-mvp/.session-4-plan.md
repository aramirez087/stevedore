## Key Design Decisions

### 1. One transport protocol per scheme — dependency injection boundary

`SFTPTransport`, `FTPTransport`, `WebDAVTransport`, `S3Transport` abstract over
their backing library (Citadel, URLSession, Soto). Tests inject fakes; production
uses the real transport. Library API changes affect exactly one file per scheme.

### 2. Providers are `actor` types with `nonisolated enumerate`

Each provider is an `actor` whose `enumerate(at:options:)` is `nonisolated`
(required by `FileSystemProvider`). It creates an `AsyncThrowingStream` that
spawns a `Task` calling a private actor-isolated helper — the same pattern as
`InMemoryFileSystemProvider` in Core. Avoids "cannot call actor-isolated method
from outside the actor" compile errors under Swift 6 strict concurrency.

### 3. `RemoteSession<Transport>` — generic actor for connection lifecycle

A single generic actor handles:
- Retry with exponential backoff and jitter (`RetryPolicy.delay(forAttempt:)`)
- Idle-timeout disconnect (`Task { [weak self] in try? await Task.sleep … }`)
- Cancellation propagation (`try Task.checkCancellation()` at entry and in retry loop)
- Transport reuse until the next `RemoteError` or explicit `disconnect()`

Tests exercise this using `RemoteSession<Int>` — no real transport needed.

### 4. `S3ListPage` return type avoids `large_tuple` lint violation

`listObjects` returns the named struct `S3ListPage` (objects + prefixes +
nextToken) instead of a 3-element tuple. SwiftLint's `large_tuple` rule rejects
tuples with ≥ 3 elements under `--strict`.

### 5. `OSAllocatedUnfairLock` in fakes (not `NSLock`)

`NSLock.lock()` carries `@available(*, noasync)` in Swift 6. All test fakes
use `OSAllocatedUnfairLock<State>` which is `Sendable` and safe in async test
contexts.

### 6. `@unchecked Sendable` with justifying comments

`CitadelSFTPTransport` is `@unchecked Sendable` because `SFTPClient` and
`SSHClient` are pre-Swift-6 types; thread safety is guaranteed by NIO event loop
internally but `Sendable` annotations are absent. `PropFindParser` is `@unchecked
Sendable` because `NSObject`/`XMLParserDelegate` cannot be retroactively
`Sendable`; the parser is created fresh per `parse(data:)` call and never escapes.

### 7. `.swiftformat --disable wrapMultilineStatementBraces`

SwiftFormat's `wrapMultilineStatementBraces` (puts `{` on a new line) conflicts
with SwiftLint's `opening_brace` rule (wants `{` on the same line). The directive
`--disable wrapMultilineStatementBraces` is present in `.swiftformat` and resolves
the incompatibility. Do not remove it.

### 8. `UncheckedSendableBox<T>` for Citadel SSH auth

`SSHAuthenticationMethod` (Citadel) is not `Sendable`. The factory closure for
`RemoteSession` is `@Sendable`. A private `struct UncheckedSendableBox<T>: @unchecked Sendable`
bridges the gap — created once, consumed once during the SSH handshake; no
actual cross-thread mutation.

### 9. FTP MLSD preferred; LIST fallback automatic

`FTPProvider.listEntries(at:)` calls `transport.mlsd` first. `URLSessionFTPTransport`
throws `.unsupported`, triggering the catch and a `transport.list` call. UTF-8
decode is tried first; if `\u{FFFD}` replacement characters appear, ISO-Latin-1
is retried.

### 10. S3 rename = buffered copy + delete

S3 has no native RENAME. `S3Provider` collects the source object into `Data`
via `collectObject`, calls `putObject` at the destination key, then `deleteObject`
at the source key. This is memory-bound for large objects — a known limitation.

### 11. S3 virtual directories from common prefixes

`listObjectsV2` with `delimiter: "/"` returns common prefixes as virtual directory
entries. The provider yields them as `FileItem(kind: .directory)`. A root-path
call (`path.isRoot == true`) invokes `listBuckets` instead.

### 12. Auth strategy matrix

| Scheme  | `password` | `privateKey` | `oauthToken` | `anonymous` |
|---------|-----------|-------------|-------------|------------|
| `sftp`  | ✅ username+password | ✅ Ed25519 PEM (32-byte raw key) | ❌ → anonymous | ❌ |
| `ftp`   | ✅ | ❌ → anonymous | ❌ → anonymous | ✅ |
| `webdav`| ✅ Basic | ❌ → anonymous | ✅ Bearer | ❌ |
| `s3`    | ✅ accessKeyID=username, secret=password | ❌ → anonymous | ❌ → anonymous | ❌ |

### 13. SFTP Ed25519 key parsing (MVP limitation)

`CitadelSFTPTransport` extracts 32 raw bytes from the base64-encoded PEM body
and passes them as `Curve25519.Signing.PrivateKey(rawRepresentation:)`. Full
OpenSSH format parsing (RSA, ECDSA, encrypted keys) is deferred.

## Risks and Mitigations

| Risk | Mitigation |
|------|-----------|
| Citadel API drift (declared 0.7, resolved 0.12) | All Citadel calls isolated in `CitadelSFTPTransport.swift`; one file to update if API changes |
| Soto API drift | All Soto calls isolated in `SotoS3Transport.swift` |
| URLSession FTP `STOR` unreliable on macOS 14 for large files | Tests use `FakeFTPTransport`; `URLSessionFTPTransport` comment documents limitation |
| FTP MLSD unavailable via URLSession | `mlsd()` throws `.unsupported`; `FTPProvider` falls back automatically |
| `RemoteSession` idle-timer `[weak self]` deallocation | If deallocated before timer fires, disconnect is silently skipped — safe for the session |
| WebDAV ETag cache not wired to conditional PUT | ETag cache built during enumeration; `If-Match` header not sent on PUT; documented limitation |
| S3 rename buffers full object in memory | Known limitation; server-side copy deferred to Session 10 (operations engine) |
| `AWSClient` not explicitly shut down | Safe for MVP; macOS cleans up on process exit |
| Strict concurrency warnings from Soto/Citadel transitive | `@unchecked Sendable` boxes with justifying comments; verified clean under `-warnings-as-errors` |
| `NSLock` unusable in async test contexts | All fakes use `OSAllocatedUnfairLock` |

## What This Session Does NOT Implement

- Real SSH host-key validation (Citadel `.acceptAnything()` used for MVP).
- Full OpenSSH private key format parsing (only 32-byte raw Ed25519 supported).
- FTP EPSV negotiation (handled transparently by the macOS network stack).
- WebDAV conditional PUT via `If-Match` (ETag cache built, header not sent yet).
- S3 server-side copy for rename of large objects (buffered in memory instead).
- SMB provider (`.smb` scheme present in `ConnectionScheme` but no factory registered).
- `OperationProgressReporting` with real byte counts (parameter accepted but not driven).
- Explicit `AWSClient` shutdown hook.
- `watch(_:)` FSEvents equivalent for remote providers (returns empty `AsyncStream`).
