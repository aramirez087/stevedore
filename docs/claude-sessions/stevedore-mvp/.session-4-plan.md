## Key Design Decisions (as implemented)

### 1. One transport protocol per scheme — dependency injection boundary

`SFTPTransport`, `FTPTransport`, `WebDAVTransport`, `S3Transport` each abstract
over their backing library (Citadel, URLSession, Soto). Tests inject fakes;
production injects the real transport. Library API changes affect only one file.

### 2. Providers are `actor` types with `nonisolated enumerate`

Each provider is an `actor` whose `enumerate(at:options:)` is `nonisolated`
(required by `FileSystemProvider`). It creates an `AsyncThrowingStream` that
spawns a `Task` calling a private actor-isolated helper — the pattern from
`InMemoryFileSystemProvider` in Core. This avoids "cannot call actor-isolated
method from outside the actor" compile errors.

### 3. `RemoteSession<Transport>` — generic actor for connection lifecycle

A single generic actor handles retry (exponential backoff with jitter),
idle-timeout disconnect, and cancellation propagation for all four schemes.
The `Transport` type parameter is bound at the provider's init site. Tests use
`RemoteSession<Int>` to verify lifecycle behaviour without any real transport.

### 4. `S3ListPage` return type avoids `large_tuple`

`listObjects` returns the named struct `S3ListPage` (objects + prefixes +
nextToken) instead of a 3-element tuple. SwiftLint's `large_tuple` rule rejects
tuples with ≥ 3 elements under `--strict`.

### 5. `OSAllocatedUnfairLock` in fakes (not `NSLock`)

`NSLock.lock()` is `@available(*, noasync)` in Swift 6 and cannot be called
inside `async` test contexts. All test fakes use
`OSAllocatedUnfairLock<State>` which is `Sendable` and works in async contexts.

### 6. `@unchecked Sendable` with justifying comments

`CitadelSFTPTransport` is `@unchecked Sendable` because `SFTPClient` and
`SSHClient` are pre-Swift-6 types that are thread-safe internally (NIO event
loop) but lack `Sendable` annotations. `PropFindParser` is `@unchecked Sendable`
because `NSObject`/`XMLParserDelegate` are not retroactively `Sendable`;
the parser is created fresh per call and never escapes.

### 7. `.swiftformat` — `--disable wrapMultilineStatementBraces`

SwiftFormat's `wrapMultilineStatementBraces` (puts `{` on new line) conflicts
with SwiftLint's `opening_brace` rule (wants `{` on same line). The directive
`--disable wrapMultilineStatementBraces` was added to `.swiftformat` to resolve
the mutual incompatibility — confirmed present in the repo.

### 8. `UncheckedSendableBox<T>` for Citadel SSH auth

`SSHAuthenticationMethod` (Citadel) is not `Sendable`. The factory closure
for `RemoteSession` is `@Sendable`. A private `struct UncheckedSendableBox<T>: @unchecked Sendable`
bridges the gap. The box is created once and consumed once during the SSH
handshake — no actual cross-thread mutation.

### 9. FTP MLSD preferred; LIST fallback is automatic

`FTPProvider.listEntries(at:)` calls `transport.mlsd(at:)` first. If it throws
(as `URLSessionFTPTransport` does, returning `.unsupported`), it falls back to
`transport.list(at:)`. UTF-8 decoding is attempted first; if
`\u{FFFD}` replacement characters appear, ISO-Latin-1 is retried.

### 10. S3 rename = buffered copy + delete

S3 has no native rename. `S3Provider` collects the source object into memory
via `collectObject`, puts it at the destination key, then deletes the source.
This is bounded to reasonable sizes in practice; large-object server-side copy
is deferred to Session 10 (operations engine).

### 11. S3 virtual directories from common prefixes

`listObjectsV2` with `delimiter: "/"` returns common prefixes as virtual
directory entries. The provider yields these as `FileItem(kind: .directory)`.
Root path (`isRoot == true`) triggers `listBuckets` instead.

### 12. Auth strategy matrix

| Scheme  | `password` | `privateKey` | `oauthToken` | `anonymous` |
|---------|-----------|-------------|-------------|------------|
| `sftp`  | ✅ username+password | ✅ Ed25519 PEM (32-byte raw key extracted) | ❌ → anonymous | ❌ |
| `ftp`   | ✅ | ❌ → anonymous | ❌ → anonymous | ✅ |
| `webdav`| ✅ Basic | ❌ → anonymous | ✅ Bearer | ❌ |
| `s3`    | ✅ accessKeyID=username, secret=password | ❌ → anonymous | ❌ → anonymous | ❌ |

## Risks and Mitigations

| Risk | Mitigation |
|------|-----------|
| Citadel API drift from declared version 0.7→resolved 0.12 | All Citadel calls isolated in `CitadelSFTPTransport.swift`; single file to update if API changes |
| Soto API drift | All Soto calls isolated in `SotoS3Transport.swift` |
| URLSession FTP STOR unreliable on macOS 14 for large files | Tests use `FakeFTPTransport`; `URLSessionFTPTransport` note added in comments |
| FTP MLSD unavailable in URLSession | `mlsd()` throws `.unsupported`; `FTPProvider` falls back automatically |
| `RemoteSession` idle-timer weak-self deallocation | `[weak self]` in timer Task; if deallocated, disconnect is silently skipped (safe) |
| WebDAV ETag cache not wired to conditional PUT | ETag cache built during enumeration; If-Match header not yet sent on PUT. Documented as limitation |
| S3 rename buffers full object in memory | Known limitation; deferred to Session 10 |
| AWSClient not explicitly shut down | Safe for MVP; macOS cleans up on process exit |
| Strict concurrency warnings through Soto/Citadel transitives | `@unchecked Sendable` boxes used with justifying comments; verified clean under `-warnings-as-errors` |

## What This Session Does NOT Implement

- Real SSH host-key validation (Citadel `.acceptAnything()` used).
- FTP EPSV negotiation (handled transparently by macOS network stack).
- WebDAV conditional PUT via If-Match (ETag cache built, header not sent).
- S3 server-side copy for rename of large objects.
- SMB provider (`.smb` scheme exists in Core but no factory registered).
- `OperationProgressReporting` with real byte counts (parameter accepted but not driven).
- Explicit `AWSClient` shutdown hook.
