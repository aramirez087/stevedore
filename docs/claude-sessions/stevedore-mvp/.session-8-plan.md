## Key design decisions

1. **`textOnAccent` as 10th token.** SDButton needs white text on primary (accent) and destructive
   (danger) fills. A raw `Color.white` literal would violate the exit criterion "no raw Color
   literals." `textOnAccent: Color(nsColor: .white)` keeps button foreground sourced from a token.

2. **`@Entry` macro for EnvironmentValues.** SwiftFormat 0.59's `environmentEntry` rule rewrites
   the classic `EnvironmentKey` struct to `@Entry` automatically. Write it with `@Entry` from the
   start to avoid a format diff.

3. **Dictionary for `IconRegistry.symbolName(forExtension:)`.** A switch with 30+ extension cases
   exceeds SwiftLint's cyclomatic_complexity limit (strict mode: 10). The dictionary lookup
   `extensionSymbols[ext.lowercased()] ?? "doc"` has complexity 1.

4. **`SDListRow` uses `Color.clear` for unselected background.** `Color.clear` is a transparency
   utility, not a design color; SwiftLint does not flag it. Documented exception.

5. **`NSHostingView` smoke tests; no ViewInspector.** `Package.swift` is frozen; ViewInspector is
   not available. Instantiating `NSHostingView(rootView: view)` is non-nil iff the view body
   compiles and runs without crashing. All test methods are `@MainActor` — `NSHostingView` requires
   the main thread.

6. **Preview files ship in production binary.** `Package.swift` is frozen; no preview-only target.
   Binary size is not a concern at MVP stage. Mitigation path if needed: `#if DEBUG` or
   `canImport(DeveloperToolsSupport)` guard.

7. **Supporting enums are top-level files.** `SDButtonStyle`, `SDLabelVariant`, `SDListRowContent`,
   `IconSize` each live in their own file — consistent with Session 01's pattern for avoiding the
   SwiftLint `nesting` rule violation.

8. **`public extension View` for `theme(_:)`.** SwiftFormat's `extensionAccessControl` rule hoists
   access control to the extension declaration. Write `public extension View { func theme(...) }`
   to avoid a format diff.

## Risks and mitigations

| Risk | Likelihood | Mitigation |
|------|-----------|-----------|
| SwiftLint cyclomatic_complexity in IconRegistry | None | Dictionary used; complexity = 1 |
| `@State` warning under `-warnings-as-errors` | None | All stateful previews use `@Previewable @State` |
| `@Entry` macro macOS version constraint | None | `@Entry` is compile-time only; no runtime OS constraint |
| Placeholder deletion breaks smoke tests | None | `DesignSystemModule.moduleName` sentinel preserved in `DesignSystemModule.swift` |
| `NSHostingView` off-main-thread crash | None | Entire test class annotated `@MainActor` |
| SwiftFormat extensionAccessControl rewrite | None | `public extension View` written from start |
| trailing_comma conflict SwiftFormat / SwiftLint | None | Resolved in Session 01: `mandatory_comma: true` in `.swiftlint.yml` |
