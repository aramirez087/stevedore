# Session 10 Implementation Plan — File Operations Engine

## Context Summary

Session 10 builds the `FeaturesOperations` module: a queue-driven engine that executes batched
file operations across any `FileSystemProvider`, with progress reporting, conflict resolution,
cancellation, and pause/resume. It depends only on `Core`; it must never reach into
`FileSystemLocal`, `FileSystemRemote`, or `FileSystemArchive` concrete types.

### Prerequisites

- Session 01: `Core` module with `FileSystemProvider`, `OperationDescriptor`, `OperationResult`,
  `ConflictPolicy`, `OperationProgressReporting`, and `InMemoryFileSystemProvider`.
- Session 02: `Core.AsyncSequence+Helpers` (`throttled`, `chunked`) available but not required.
- Session 03: `LocalFileSystemProvider` exists; `DataReadableProvider` conformance deferred.
- Session 04: Remote providers exist; `DataReadableProvider` conformance deferred.
- Session 05: `ArchiveProvider` exists; no Operations dependency.
- Session 09: `OSLogger` / `AppLogger` available; logging not used in this session.

### Critical constraints

1. **`Foundation.OperationQueue` naming conflict** — The actor must be named `FileOperationQueue`,
   not `OperationQueue`, to avoid collision with the Foundation class. The source file keeps its
   specified name `OperationQueue.swift`; the type name differs.

2. **`Core.ConflictPolicy` already exists** — `Sources/Core/Types/OperationKind.swift` defines
   `public enum ConflictPolicy { case ask, overwrite, skip, rename }`. `ConflictPolicy.swift` in
   `FeaturesOperations` must NOT redeclare this enum. It contains `ConflictResolution` (the
   concrete outcome) and `ConflictResolver` (the actor implementing `.ask` suspension).

3. **`FeaturesTests` cannot import FileSystem modules** — `Package.swift` `FeaturesTests` target
   depends on `Core` + feature targets only. All tests use `TestDataProvider` (defined in the
   test target) or `Core.InMemoryFileSystemProvider`.

4. **No `read(at:)` on `FileSystemProvider`** — The Core protocol has no byte-reading method.
   `CrossProviderCopy.swift` defines `DataReadableProvider` and `DataWritableProvider` protocols
   that extend `FileSystemProvider`. Real providers add conformance in their own sessions.

5. **Smoke test must stay green** — `FeaturesOperationsSmokeTests` asserts
   `FeaturesOperationsModule.moduleName == "FeaturesOperations"`. The sentinel re-declared in
   `FeaturesOperationsModule.swift` (replacing `Placeholder.swift`).

6. **SwiftFormat paths-before-flag** — Run as `swiftformat <paths> --lint`, not
   `swiftformat --lint <paths>` (SwiftFormat 0.59 argument parser bug).

7. **Trailing comma rule** — `.swiftlint.yml` has `trailing_comma: mandatory_comma: true`.
   All trailing commas in arrays/function calls are required.

8. **`AsyncThrowingStream<T, any Error>` not existential `AsyncSequence`** — macOS 14 target
   cannot use the two-primary-associated-type constrained existential for `AsyncSequence`.

9. **SwiftLint `nesting` rule** — Enums nested inside actors/classes are forbidden. `OperationState`
   must be top-level, not nested inside `Operation`.

10. **`OperationDescriptor.ID` not `UUID`** — `Operation.ID` is a typealias for `OperationDescriptor.ID`
    (which is itself `UUID`). Do not hard-code `UUID` as the ID typealias.

### `Operation.swift`

`OperationState` is declared at module level (not nested) to satisfy SwiftLint's `nesting` rule.

```swift
// Top-level to satisfy SwiftLint nesting rule.
public enum OperationState: Sendable {
    case pending
    case active
    case paused
    case completed(OperationResult)
    case failed(any Error)
    case cancelled
}

public struct Operation: Sendable, Identifiable {
    public typealias ID = OperationDescriptor.ID    // NOT bare UUID

    public let id: ID
    public let descriptor: OperationDescriptor
    public internal(set) var state: OperationState
    public internal(set) var progress: TransferProgress

    public init(descriptor: OperationDescriptor) {
        id = descriptor.id
        self.descriptor = descriptor
        state = .pending
        progress = TransferProgress(operationID: descriptor.id)
    }
}
```

### `OperationQueue.swift` — `FileOperationQueue` actor

```swift
public actor FileOperationQueue {
    public let maxConcurrency: Int                          // default 2

    private var operations: [Operation] = []                // single source of truth
    private var activeTasks: [Operation.ID: Task<OperationResult, any Error>] = [:]
    private var gates: [Operation.ID: PauseResumeGate] = [:]
    private var continuations: [UUID: AsyncStream<[Operation]>.Continuation] = [:]
    private let executor: OperationExecutor

    public init(executor: OperationExecutor, maxConcurrency: Int = 2)

    // Public API — enqueue is sync (no await needed)
    public func enqueue(_ descriptor: OperationDescriptor)

    // These are async because they await actor-isolated gate methods
    public func cancel(_ id: Operation.ID) async
    public func pause(_ id: Operation.ID) async
    public func resume(_ id: Operation.ID) async
    public func cancelAll() async

    // Subscription — nonisolated factory; uses unstructured Task for continuation registration
    public nonisolated func operationStream() -> AsyncStream<[Operation]>

    // Internal
    private func drain()
    private func finish(_ id: Operation.ID, result: Result<OperationResult, any Error>) async
    private func broadcast()
    private func register(id: UUID, continuation: AsyncStream<[Operation]>.Continuation)
    private func unregister(id: UUID)
}
```

**Concurrency cap**: `drain()` starts `min(pending.count, maxConcurrency - activeTasks.count)`
new Tasks. Each Task calls `executor.execute(_:gate:)`. On completion, `finish` is called, the
operation state is updated, and `drain()` runs again.

**`cancel` wakes the gate**: For active/paused ops, after cancelling the task, wake the gate via
`gate.resume()` so the task can observe `Task.isCancelled` at the next `checkPoint()`.

**Observation pattern**: Each active task is watched by a detached `Task { await finish(id, result) }`
that awaits `task.value`. This avoids a retain cycle on `self`.

### `OperationExecutor.swift`

```swift
public struct OperationExecutor: Sendable {
    public let providers: [ConnectionScheme: any FileSystemProvider]
    public let conflictResolver: ConflictResolver
    public let progressTracker: TransferProgressTracker

    public init(
        providers: [ConnectionScheme: any FileSystemProvider],
        conflictResolver: ConflictResolver,
        progressTracker: TransferProgressTracker
    )

    public func execute(_ operation: Operation, gate: PauseResumeGate) async throws -> OperationResult
}

// Private adapter
private struct ProgressBridge: OperationProgressReporting {
    let operationID: OperationDescriptor.ID
    let tracker: TransferProgressTracker
    func report(_ coreProgress: Core.Progress) async
}
```

**Scheme resolution**:
```
primaryScheme = sources.first?.scheme ?? destination?.scheme
```
This handles destination-only ops (`.mkdir`) with no sources. Throws `.invalidArgument` when
neither is set.

**Dispatch logic**:
1. `destScheme == nil || destScheme == srcScheme` → `executeSameProvider` → `provider.execute`
2. `destScheme != srcScheme` → `executeCrossProvider` → `CrossProviderCopy` (requires both
   providers to conform to `DataReadableProvider`/`DataWritableProvider`)

**Conflict detection** (same-provider): Before delegating, check `attributes(at: destination)` —
if the destination exists and the op is `.copy` or `.move`, invoke `conflictResolver.resolve`.
On `.skip`, return early with `OperationResult(status: .skipped, ...)`.

**Conflict detection** (cross-provider): Same logic; `.renameWithSuffix` collects existing paths
at `destination.parent` via `enumerate`, calls `ConflictResolver.uniquePath`, then copies to the
unique path.

**`@discardableResult collectPaths`**: Static helper `collectPaths(at:provider:)` returns
`Set<FilePath>` gathered from `provider.enumerate(at:)`; best-effort (swallows errors).

**`swiftlint:disable function_parameter_count`** regions required for:
- `CrossProviderCopy.copy(from:on:to:on:gate:progress:)` (6 params)
- `OperationExecutor.copyFile(descriptor:source:destination:readable:writable:gate:)` (6 params)

### `ConflictPolicy.swift`

```swift
// ConflictResolution — concrete outcome after policy application
public enum ConflictResolution: Sendable, Equatable {
    case skip
    case replace
    case renameWithSuffix    // appends " (N)" suffix; N starts at 2
}

public actor ConflictResolver {
    private var pendingAsks: [FilePath: CheckedContinuation<ConflictResolution, Never>] = [:]

    public init()

    // Maps Core.ConflictPolicy → ConflictResolution
    // Suspends for .ask until provide(resolution:for:) is called
    public func resolve(
        source: FilePath,
        destination: FilePath,
        policy: ConflictPolicy                  // Core.ConflictPolicy (skip/overwrite/rename/ask)
    ) async -> ConflictResolution

    // Unblocks a suspended .ask; no-op if source not waiting
    public func provide(resolution: ConflictResolution, for source: FilePath)

    // Generates unique path by appending " (2)", " (3)", … until not in existingPaths
    public static func uniquePath(for destination: FilePath, existingPaths: Set<FilePath>) -> FilePath
}
```

**Policy mapping**:
- `.skip` → `.skip`
- `.overwrite` → `.replace`
- `.rename` → `.renameWithSuffix`
- `.ask` → `withCheckedContinuation`; continuation stored in `pendingAsks[source]`

**`.ask` duplicate handling**: If a second `.ask` arrives for the same source path, the existing
continuation is immediately resolved with `.replace` (documented limitation — one ask per source).

**`uniquePath` stem/extension split**: Splits on `lastIndex(of: ".")`. Dotfiles (`.gitignore`)
have no extension, so `"."` at `startIndex` returns the whole name as stem. Extension is
appended as `"\(stem) (\(N)).\(ext)"` or `"\(stem) (\(N))"` when ext is empty.

### `TransferProgress.swift`

```swift
public struct TransferProgress: Sendable {
    public let operationID: OperationDescriptor.ID
    public var bytesCompleted: Int64           // 0 initially
    public var bytesTotal: Int64?              // nil when unknown
    public var itemsCompleted: Int
    public var itemsTotal: Int
    public var throughputBytesPerSecond: Int64?
    public var estimatedSecondsRemaining: Double?

    // nil when bytesTotal is nil or zero; clamped to 1.0 to handle bytesCompleted > bytesTotal
    public var fraction: Double? { get }

    public init(operationID: OperationDescriptor.ID)
}

public struct QueueProgress: Sendable {
    public let perOperation: [OperationDescriptor.ID: TransferProgress]

    public init(perOperation: [OperationDescriptor.ID: TransferProgress])

    public var aggregateBytesCompleted: Int64 { get }           // sum of all bytesCompleted
    public var aggregateBytesTotal: Int64? { get }              // nil if ANY op has nil total
}

public actor TransferProgressTracker {
    private let minReportInterval: Duration    // default .milliseconds(100) → 10 Hz
    private var lastReport: ContinuousClock.Instant?
    private var current: [OperationDescriptor.ID: TransferProgress] = [:]
    private var continuations: [UUID: AsyncStream<QueueProgress>.Continuation] = [:]

    public init(minReportInterval: Duration = .milliseconds(100))

    public func update(_ progress: TransferProgress) async      // throttled
    public func complete(operationID: OperationDescriptor.ID) async   // always emits

    public nonisolated func progressStream() -> AsyncStream<QueueProgress>
}
```

**Throttle in `update`**: Only calls `emit(at:)` when `now - lastReport >= minReportInterval`.
`complete` always calls `emit(at:)` regardless of throttle.

**Subscriber receives initial snapshot**: `register(id:continuation:)` immediately yields
`QueueProgress(perOperation: current)` to new subscribers.

### `Throughput.swift`

```swift
public struct ThroughputEstimator: Sendable {
    public let windowDuration: Duration        // default .seconds(5)

    private var samples: [(instant: ContinuousClock.Instant, bytes: Int64)]

    public init(windowDuration: Duration = .seconds(5))

    public mutating func record(bytes: Int64)  // trims old samples; appends current instant

    // nil if < 2 samples in window (single point cannot produce a rate)
    public var bytesPerSecond: Int64? { get }

    // 0 if bytesLeft == 0; nil if < 2 samples; positive Double otherwise
    public func estimatedSecondsRemaining(bytesLeft: Int64) -> Double?
}
```

**Window mechanics**: `record` removes samples where `instant < now - windowDuration`, then
appends. `bytesPerSecond` uses first/last sample timestamps as the elapsed denominator:
`sum(bytes) / elapsed_seconds`. Uses `guard let first, last` (not force unwraps) to satisfy
`force_unwrapping` SwiftLint rule.

**`elapsedSeconds` helper**: Extracts seconds from `Duration.components` as
`Double(seconds) + Double(attoseconds) * 1e-18` — does not use `Duration.seconds` property
(unavailable on macOS 14 without import of `_Concurrency` internals).

### `CrossProviderCopy.swift`

This file contains four public declarations:

#### `DataReadableProvider`

```swift
public protocol DataReadableProvider: FileSystemProvider {
    func read(
        at path: FilePath,
        chunkSize: Int                          // advisory hint; providers may return smaller chunks
    ) -> AsyncThrowingStream<Data, any Error>   // nonisolated in implementations
}
```

#### `DataWritableProvider`

```swift
public protocol DataWritableProvider: FileSystemProvider {
    func writeChunk(
        _ data: Data,
        to destination: FilePath,
        isFirst: Bool,                          // true: create/truncate file
        isLast: Bool                            // true: flush and close
    ) async throws

    func deletePartial(at path: FilePath) async throws   // cleanup on cancel/error
}
```

#### `PauseResumeGate`

```swift
public actor PauseResumeGate {
    private var suspended: Bool = false
    private var waiters: [CheckedContinuation<Void, Never>] = []

    public init()

    // Suspends caller via CheckedContinuation when suspended==true; returns immediately otherwise
    public func checkPoint() async

    // Sets suspended=true; future checkPoint calls will block
    public func pause()

    // Sets suspended=false; resumes all blocked checkPoint waiters
    public func resume()
}
```

`DispatchSemaphore.wait()` is banned in async contexts in Swift 6. `PauseResumeGate` uses
`CheckedContinuation` to avoid spinning.

#### `CrossProviderCopy`

```swift
public struct CrossProviderCopy: Sendable {
    public static let defaultChunkSize: Int = 256 * 1024     // 256 KB

    public let chunkSize: Int

    public init(chunkSize: Int = defaultChunkSize)

    // swiftlint:disable function_parameter_count
    public func copy(
        from source: FilePath,
        on sourceProvider: any DataReadableProvider,
        to destination: FilePath,
        on destProvider: any DataWritableProvider,
        gate: PauseResumeGate,
        progress: (any OperationProgressReporting)?
    ) async throws -> Int64
    // swiftlint:enable function_parameter_count
}
```

**Copy loop with one-chunk lookahead**:
```
1. Prime lookahead = try await iterator.next()
2. Loop while lookahead != nil:
   a. try Task.checkCancellation()         ← cooperative cancellation
   b. await gate.checkPoint()             ← pause/resume
   c. next = try await iterator.next()    ← peek ahead for isLast
   d. isLast = (next == nil)
   e. try await destProvider.writeChunk(current, ..., isFirst: isFirst, isLast: isLast)
   f. bytesCopied += chunk.count
   g. isFirst = false
   h. await progress?.report(...)
   i. lookahead = next
3. On any throw (incl. CancellationError): try? await destProvider.deletePartial(at: destination); rethrow
```

The one-chunk lookahead determines `isLast` without an extra read. Both `CancellationError` and
I/O errors trigger `deletePartial` in the `catch` block.

## Key design decisions and rationale

| Decision | Rationale |
|----------|-----------|
| `FileOperationQueue` not `OperationQueue` | Avoids shadowing `Foundation.OperationQueue` at import sites |
| `OperationState` top-level, not nested in `Operation` | SwiftLint `nesting` rule prohibits enums nested inside actors/classes under `--strict` |
| `Operation.ID = OperationDescriptor.ID` | Keeps ID type consistent across Core and Features; `OperationDescriptor.ID` is already `UUID` |
| `ConflictResolution` separate from `Core.ConflictPolicy` | Core policy is declarative input; Features resolution is imperative output (`.renameWithSuffix` generates a new path) |
| `PauseResumeGate` actor with `CheckedContinuation` | Swift 6 bans `DispatchSemaphore.wait()` on async tasks; actor + continuation is the correct pattern |
| `DataReadableProvider`/`DataWritableProvider` in `FeaturesOperations` | Core protocol surface is frozen; byte-level I/O capability is optional; real providers add conformance separately |
| One-chunk lookahead in `CrossProviderCopy` | Determines `isLast` before writing without requiring a second read of the source; necessary for `isFirst/isLast` signalling protocol |
| `OperationExecutor` is a `struct`, not `actor` | No mutable state; dispatch decisions are pure; avoids actor hop overhead in the execution path |
| `ProgressBridge` is a private `struct` | Adapts `Core.Progress` to `TransferProgressTracker.update`; scoped to `OperationExecutor.swift`; not public API |
| `primaryScheme = sourceScheme ?? destScheme` | Destination-only ops (`.mkdir`) have no sources; scheme must be inferred from destination |
| `cancel` calls `gate.resume()` after cancelling task | Wakes a paused task so it can reach the next `Task.checkCancellation()` check without hanging |
| Deadline-based polling in `FileOperationQueueTests` | `AsyncStream.next()` in a fixed loop hung when no new events arrived; polling `snapshot()` with 20ms sleeps and 5s deadline is reliable |
| `swiftlint:disable function_parameter_count` regions | `copy(from:on:to:on:gate:progress:)` and `copyFile(descriptor:source:destination:readable:writable:gate:)` each have 6 params; symmetric pairs are idiomatic Swift API design |
| `guard let first, last` in `ThroughputEstimator` | Force unwraps technically safe (guarded by `count >= 2`) but violate `force_unwrapping` rule |
| `FeaturesOperations.Operation` qualified name in tests | Prevents ambiguity with `Foundation.NSOperation` / `Foundation.Operation` at import sites |

## Risks and mitigations

| Risk | Mitigation |
|------|------------|
| `FeaturesTests` can't import `LocalFileSystemProvider` | `TestDataProvider` in test target implements all required protocols without importing FileSystem modules |
| `Foundation.OperationQueue` name collision | Type named `FileOperationQueue`; file named `OperationQueue.swift` per session spec |
| Pause-within-100ms test is timing-sensitive | Uses `ContinuousClock` deltas; asserts ≤1 chunk advanced (not a wall-clock assertion); `SlowWriteProvider` introduces per-write delay for determinism |
| `ThroughputEstimator` is not thread-safe | Documented as value type; always mutated inside single `Task`; no `@unchecked Sendable` needed |
| Concurrent `.ask` for same source path | Second `.ask` immediately resolves the first continuation with `.replace` before storing the new one — documented limitation |
| `ConflictResolver.provide` called before `resolve` | `removeValue(forKey:)` returns nil → no-op; no crash |
| SwiftLint `large_tuple` rule | All multi-field returns use named structs (`TransferProgress`, `QueueProgress`) |
| SwiftLint `nesting` rule | `OperationState` lifted to top-level |
| `OperationExecutor.collectPaths` best-effort error handling | Intentional: returning a partial set is better than failing conflict detection for an intact destination; documented with inline comment |
